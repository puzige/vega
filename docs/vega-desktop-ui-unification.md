# Issue #296 · 全应用桌面 UI 统一

## 1. 来源与范围

2026-10-11 用户授权：功能已具备，界面混乱；按现代桌面软件统一优化，先观察真实运行信息流，先规格后实现。关联 Issue #296。原生观察安装 0.1.64：用户气泡、完成汇总、长助手正文、代码、表格、连续阶段说明及 Composer。公开材料只保留视觉事实，不包含真实任务标题、内容、路径或截图。当前观察没有直接展示应用错误卡/权限审批卡，其改进需进程内合成状态验证，不能声称真实错误路径已经验收。

事实：导航轨道常驻贴着正文左缘，并从正文列扣除宽度；回到底部按钮浮在代码/表格上；助手阶段说明与结果的正文层级相同；用户轮次与过程/答案之间主要靠小间距。侧栏和标题栏已具备统一 token，本轮沿用其密度和控制尺寸，不重做导航结构。

2026-10-11 范围补充：用户明确要求考虑整个 App，包括设置。已原生只读查看 General、Providers、Reasoning、Pricing、Usage、MCP、Agents、Skills 八页并返回原任务。可观察问题：导航英文而主要表单中文；分组间距、按钮高度与状态样式不一；Skills 普通动作占满整行；Agents 输入框缺持续可见标签；提供方普通动作与删除动作层级接近。页面数据、服务地址、用量、目录及截图均不进入公开证据。

目标：一个安静的原生工作台；用户输入、过程、结果、需要处理的异常一眼可区分，长会话阅读无 chrome 遮挡。优先信息流，并通过同一内容列和控件节奏统一壳层、Composer、过程与状态。八个设置页是本轮实现范围，不作为后续事项略过。

边界：仅视觉布局/共享 token/进程内 UI 测试；不改模型、权限、安全、持久化、调度、自动折叠决策或滚动语义。不得停止、重启、安装或向当前真实任务发消息。#295 已合并（89e4c93），Composer 底栏不恢复分支；New Task utility bar 保留。旧 #291 不重开。消息复制动作仍禁用。

## 2. 冻结设计

### R1 阅读列与导航

正文与 Composer 最大宽仍为 768px，实际宽保持一致。新增 20px 导航 gutter，正文与 Composer 对称水平安全内缩 = CONTENT_PADDING(16) + 导航 gutter(20) = 36px；宽屏最大列仍居中。消息 rail 位于正文列前导 gutter，不再作为 list 的 flex 子项扣减正文宽；保留 20px hitbox、所有锚点、键盘、预览、历史定位能力。预览回退 lane 的既有行为保留，未展开预览时正文/Composer 必须同宽。

轨道 1px；静止锚点用 text_tertiary，小点 4px；当前/选中用 accent，不增加新动画。当前标记 6px，选中标记 6px。颜色/几何经主题 token，不硬编码。预览不泄露或扩展既有内容契约。

### R2 阅读恢复区域

移除覆盖正文的浮动回到底部。非空信息流底部固定 40px 导航行（32px control + 上下各4px），放在滚动正文之外、Composer 之上；尾随模式行保位但按钮不挂载。脱离尾部时居中显示中性 pill，ArrowDown + 回到底部，沿用 resume_tail、焦点、aria 和键盘 action；不显示虚构未读计数。按钮高度32、横内距12、icon/text gap8、radius16；hover bg_hover、focus accent，基态 bg_elevated + border_subtle，无阴影。

### R3 消息与过程节奏

用户消息外框上24/下16px；保留气泡15px/1.65、80%最大宽、16圆角、12/8内距与空行。助手消息上8/下16px，保留源 Markdown、15px阅读字号、选择和复制语义，所有 selectable/nonselectable 路径一致；不改用户生成正文的字重、文字或内容语义。

过程统一为中性 disclosure：RunActivity、Thinking、ToolActivityGroup、单Tool 标题行最小28px（同壳层控件高度），13px secondary，16px共享图标、gap8、内距横8；hover bg_hover、radius8、focus-visible accent；标题不跳动，不隐藏错误状态图标/标签。展开内容保持240/320高度上限和内部滚动，过程体使用13px正文/12.5px等宽而不是15px答案字号；工具失败 danger、审批 warning，状态必须来自已有数据。完成汇总依旧自动折叠，运行时仅最新活动展开；不得为了视觉改事件顺序。

### R4 异常与 Composer 一致性

复用现有错误和权限数据、恢复动作与危险确认。错误/警告使用共享16px语义图标 + 13px正文，8px内距/gap、8px圆角、border_subtle，颜色 danger/warning；没有状态色背景铺满会话。只统一现有可见状态容器，不能删除错误码/提示/动作或改变权限决策。Composer 保持20px圆角、100px最小高、底部16px、单表面，普通控件沿用28px、13px标签；模型长标签可收缩/截断并保留可访问全名，stop/send 与权限不能被挤出。顶栏46px与三固定槽位、Sidebar 32px/13px和选择层级不变，按此契约检验一致性，不新增装饰或重复状态。

### R5 八个设置页的共同语法

保留八个路由及顺序，显示名称统一为「通用、服务提供方、思考、定价、用量、MCP、Agents、Skills」；返回入口为「返回应用」。保留内部 section 索引、选择器与键盘 action。导航沿用 Sidebar 的32px行高、13px字、8px圆角和中性 active 表面，hover/focus 不改变几何。

保留744px最大内容列及当前 Sidebar 同宽 rail；页标题沿用24px token，标题下16px进入内容，区块之间24px，区块内部12px，字段label与说明4px、动作组8px。窄窗允许动作组换行，内容区 min-width 为0，长内容在原滚动区域内完整可达，不能通过裁切消除溢出。新增有语义的 Settings token 承载这些共享值，组件不写死共享几何。

八页共用轻量 section/action/status renderer，不引入新的组件框架：

- 通用：外观与布局、默认项、更新形成独立分组。主题、权限、模型及更新开关均保留真实 handler/guard。
- 服务提供方：保留列表与详情架构，列表选中与导航一致；普通操作中性，删除使用 danger；已存凭据继续遮罩，不能扩大展示。保留窄窗有界布局。
- 思考、定价：统一分组和卡片内距；已有能力、档位和价格编辑完整保留，不替换为新交互模型。
- MCP、Skills：标题/说明/动作/状态顺序统一。刷新、检查、导入等普通按钮随内容收缩，动作组可换行，不再占满整列；布尔项的标签与控件分列对齐。授权/导入确认保留完整说明与所有确认动作，不折叠安全信息。
- Agents：名称、可执行文件、参数三个字段均加持续可见标签；保留原输入实体、字段校验和保存语义。
- 用量：统一页头、加载/空态/错误及操作；图表、计量单位、筛选和统计数据语义不变，不在本轮改图表算法。

设置按钮最小高28px，横内距12px、8px圆角、13px文字；窄窗长标签可增高。普通按钮 bg_elevated/border_subtle/text_primary；主保存动作 brand_primary/brand_on_accent；危险动作用 danger文字和中性边界，不铺大红面。disabled 不响应且文字降级，保留原因。每个有 hover 的可交互元素具稳定身份，键盘 focus-visible 使用 accent 且不引起位移。不得为统一外观改变触发次数或 FocusHandle 所有权。

状态行采用16px共享图标、13px文案、8px间距/内距/圆角和中性细边界；error danger、warning warning、success success，loading/empty secondary。状态来自现有typed state，原错误码、恢复动作和风险说明不得丢失；普通加载不以错误边框表达。

### R7 图标对齐与交互动效（2026-10-11 用户追加）

用户补充感受：Icon与正文没有居中，hover前后反馈和动效不足。本轮增加共享交互层的检查与修复，不把这一诉求缩成局部图标替换。继续使用已有原生SVG图标集，不生成位图图标或引入装饰图标。

- 所有共享功能图标使用 `Layout::ICON_SIZE=16` 的固定、不可压缩、居中容器，不受父文字line-height扩大。图标按钮在既有命中框中心绘制；单行图标+标签行以13px正文/1.55行盒为基准垂直居中。多行错误/权限说明的图标与首行行盒居中，不与整段高度居中。检查内置KitIcon与inline SVG两条路径，不靠每个图标独立的负margin矫正。
- 稳态、hover、pressed、selected、focus、disabled之间保持hitbox、padding、border占位和文字位置不变。hover要有可见中性反馈，离开后恢复；pressed即时显示并在释放/离开后清除；selected保持其真实选中表面，disabled不接受触发也不播放交互动效。
- 共享控件hover进入与离开采用120ms短过渡，使用 `Motion::INTERACTION_DURATION_MS`。优先只插值背景/透明度，允许中途反转且从当前值平滑继续；结束后停止请求动画帧。不移动正文、缩放图标、改变列表高度、添加循环pulse/shimmer或模拟执行进度。状态/审批出现必须即时可读，不能为动画延迟真实交互。
- 覆盖共享图标按钮、标题栏控件、Sidebar主要导航行、Settings按钮/导航与信息流过程disclosure；通过一个原生共享交互实现接入，不逐页复制计时器。保持各处原有mouse/keyboard handler、FocusHandle及点击次数；纯绘制层不能拦截或穿透既有事件。
- 尊重系统Reduce Motion：通过公开NSWorkspace API在启动、应用回到前台、交互开始时只读同步GPUI的reduce-motion状态；运行中设置变化在下一次前台/交互生效，不声称实时订阅系统通知。不写入或更改用户设置。启用时直接绘制最终静态状态，不启动/持续请求动画帧；平台读取失败时使用静态反馈。系统桥接只负责展示偏好，不读取其他配置；允许最小macOS Objective-C runtime FFI，不新增依赖。

算术：13×1.55=20.15px行盒，16px图标居中上下余量各(20.15−16)/2=2.075px；28px命中框中的16px图标上下左右余量均(28−16)/2=6px。这里对齐的是布局盒，字形光学效果仍由用户原生手测确认。
