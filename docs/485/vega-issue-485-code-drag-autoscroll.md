# 代码块拖选边缘自动横向滚动

Issue：[#485](https://github.com/puzige/vega/issues/485)，同一用户反馈的独立修复周期；PR：[#511](https://github.com/puzige/vega/pull/511)。

## 范围与基线

用户确认操作为按住鼠标左键拖选代码文字，移到代码视口的左右边缘没有自动横向滚动；要求继续修复并补充实际交互回归，不使用 CUA。不是悬停即滚动，也不是把纵向滚轮自动转换为横向滚轮。

本轮起始生产基线为 `99e270b13c0f4def33492c432ba25bd81244c2a3`。测试冻结前再次 fetch，远端 master 从 `3a2ef8e9795d609f022b7b81011360db102e3de6` 更新至 `9baca7519d97995267de31eb9c2e213f0c171e67`；保护测试草稿后同步，当前未修复生产基线为 `db4e27851bdf83d2e49710d0f8707998f9c6b089`。新增上游仅为 #512 侧栏排序，UI、Cargo 与工作流生产文件相对起始基线未变。原先已发布的引用周期提交保留在合并祖先中，不强推丢失证据。沿用独立 worktree 和 `fix/485-markdown-quote-wrap` 分支；主仓库的用户未提交文件不修改，不倒改既有测试来追认本轮交互。

引用块中的普通正文应按可用宽度自然折行；围栏代码块应保留原有字符、缩进与长行，通过横向滚动查看。本轮不撤销引用正文的两个宽度容器，不改变引用折行、代码不软折行、Markdown 解析或源文。引用内的围栏代码结构重做不在本轮范围。

## 已确认事实

- `render_rows.rs::markdown_blocks` 已给代码内容设置 `.overflow_x_scroll()`；`scroll_edge_fade` 使用持久 ScrollHandle。仅增加 overflow 样式不能解决缺失的拖选边缘行为。
- `selection.rs::SelectableMessage` 把消息文档统一登记为选择参与者，代码块是该文档的内部滚动视口。
- 锁定 `gpui-base 0.6.1` 的选择自动滚动只计算纵向位移，合成滚动事件的横向量为零；该上游行为不足以自动驱动内部代码视口。
- 既有普通消息选区部分依赖屏幕几何，内部横向滚动后必须保持逻辑锚点，不能只让代码画面滚动而让选中字符漂移。
- 上一周期的代码保护仅验证不软折行、内容投影与高度，不曾驱动拖选事件或验证 scroll offset。其 GREEN 不证明本轮交互正常。

## 先行验收矩阵

先写齐以下必要交互测试并在生产行为未修改时冻结。所有验证使用生产 Markdown 渲染、真实 GPUI 测试平台事件/重绘/调度器和选区复制入口。不得直接写 scroll offset、selected_text 或选区索引制造通过，也不以样式/源码字符串、帮助函数数学断言替代交互。

| ID | 操作 | 可观察结果 |
|---|---|---|
| D1 | 在超宽代码行内左键按下，拖到右边缘后保持鼠标不动，推进至少两个时间步 | 代码视口横向 offset 连续向右推进；后续隐藏字符出现且选区扩展，逻辑起点保持原字符；外层纵向 offset 不变 |
| D2 | 通过真实横向滚动手势到达有左侧隐藏内容的位置，或沿 D1 实际滚动后拖向左缘并保持 | 自动向左滚动并正确收缩/反向扩展选区；回到最左/最右后 offset 有界、不抖动、不越界 |
| D3 | 自动滚动期间松开左键；或仍按住但把指针移回视口中央 | 后续时间步 offset 不再变化；松键保留最终有效选区，移回中央时 cursor 仍响应此次真实移动；后续计时步不再改变范围，复制对应准确字符 |
| D4 | 未按键只悬停/移动到边缘；或拖选不溢出的短代码块 | 不触发横向自动滚动，不制造空白或全局滚动 |
| D5 | 同一消息有两个独立代码块，或相邻消息有另一代码块 | 只滚动本次手势所属的视口；兄弟代码块和相邻消息位置不变；指针离开所属代码行的纵向范围后不误滚兄弟块 |
| D6 | 拖选跨越 UTF-8 中英文与标点，持续自动滚动后经真实选区复制入口读取剪贴板 | 复制为冻结源文的精确逻辑子串；不丢失/增加字符，不含围栏、语言标题、复制按钮或相邻块；首个锚点不会随 scroll offset 漂移 |
| D7 | 拖选时清空选区、焦点转到同窗口其他控件、窗口失活、内容被移除/替换或代码容器不再可见 | 后续时间步停止自动滚动，无旧句柄继续驱动其他内容或窗口 |
| D8 | 在展开思考正文内的长代码块执行左右边缘拖选 | 同样持续横向滚动并保持逻辑选择；不破坏原有思考纵向滚动、局部视口和选区复制 |
| D9 | 普通引用段落和代码块显示、手动横向滚动与外层纵向阅读 | 保留引用正文折行和代码不软折行；手动横滚不回跳，普通正文的纵向选择行为不被横向机制抢走 |

D1–D8 可以少量表驱动测试覆盖，不为每个内部字段制造用例。长行使用合成内容，不访问用户会话或外部网络。精确样本和断言以测试先行提交为准；当前尚无行为 RED。D6 可从已知非零字符 anchor 拖到完整行末/行首并滚到相应边界，复制必须逐字等于预先写定的后缀/前缀字面量，不从实际 range 或选中输出反推预期。停止用例必须在尚有滚动余量时取消，再推进多个独立时间步，不能拿已到边界冒充停止；待重绘松键不派发过期 held move。

## 约束与交付顺序

只在 Vega UI 的选择与代码视口边界实现，不改 registry 缓存、锁定框架版本、解析器、权限、持久化、字体或颜色。不新增依赖、可见说明、第三方框架副本、生产公共 API。可用现有 gpui_kit dev-only test-support 和透明的私有只读观测；生产实现须委派专职子 agent，主控审查集成。

### 冻结前实现计划

1. 在 `conversation_stream/selection.rs` 增加私有的横向选择视口包装器或同职责模块；它与代码 fade 共用真实 ScrollHandle，观察代码视口与裁剪区域交集，以真实选区快照及左键手势确定唯一驱动者。不修改通用 fade 的滚动行为。
2. `render_rows.rs::markdown_blocks` 的可选择代码视口接入包装器，保留现有 ID、宽度、内距、代码构造与两个引用正文容器。`thinking_body.rs::BodyElement` 的 code 横向分支接入同一机制，复用既有逐块句柄，不重做虚拟排版。
3. `SelectableMessage` 对普通 Markdown 复用现有 content-key resolver / 逻辑范围投影链路，固定原字符锚点；不能把单个代码块 offset 作为整条消息 offset，不能绕过 MessageCopy 的内容/选区失效。
4. 活跃拖选在左右触发区停留时持续调度；只改变所属代码块的 x offset，夹紧到真实可滚动范围，保留 y。重绘后通过正常 GPUI 事件/选择更新路径重新解析保持指针的 cursor，不能直接写选区索引。停止条件为 D3、D7；不得在无拖选、失活或卸载后空转。
5. 测试可只读捕获现有 fade 的真实 ScrollHandle 和已排版文字坐标，使用真实 down/move/up/wheel、分步时钟推进和重绘，再从生产选区复制入口读取测试剪贴板。测试观测器不注入生产容器、宽度或滚动决策。先写齐 D1–D9 相关边界，审查后冻结再跑 RED。

独立架构审查约束：持久状态按窗口、消息选择参与者、代码身份隔离，不能只用 block ordinal；初次按下时 collapsed selection 可能没有 snapshot，不可据此丢失手势归属。MessageCopy selection_generation 随 SelectionChanged 变化，不可作为不变手势 token。普通消息仅复用逻辑 key 范围解析，不直接套用包含内容失效职责的 Thinking projected 标志。ScrollHandle::set_offset 不自行夹紧，必须显式限制为 `[-max_offset.x, 0]`。fade 和驱动必须共用同一句柄，不能被 scroll_edge_fade 另建句柄覆盖。原框架继续负责纵向自动滚动，不启用整消息 self_scroll 或另起纵向驱动。冻结测试应包含失活/清除/移除、待重绘时松键、非左键、两窗口隔离及纵向边缘/corner handoff；防止 x-only scroller 把原纵向自动滚轮误映射成横向滚动。

生产尚未修改时先提交测试，复用 draft PR 的现有 Actions 确认目标行为失败；编译、环境或接线错误不是有效 RED。固定输入/预期后最小实现，用同一测试取得 GREEN，固定可恢复补丁与完整提交/run/job/原始计数，再独立删除 Rust 测试及独占接线；保留先前引用证据。最终 latest head 的完整 PR gate 必须通过并明确 `no Rust tests`（0 发现/0 执行），空集不替代带测试 GREEN。

本地只做快速差异、格式、元数据和静态检查；不运行 Vega，不编译、构建、打包、Cargo check/Clippy/test/nextest。不使用 CUA。云端只复用现有 pr-check，不增调度设施；检查启动后每 5 分钟查询，禁止 watch/短轮询。原生字体与实际系统鼠标体验交用户手测；自动事件回归是进程内验证，不冒充真实桌面验收。

回滚仅撤销本轮代码拖选机制，保留已验证的引用折行；不涉及用户数据。实现、云端验证、审查合并和用户手测分别报告，未手测通过不关闭 Issue。
