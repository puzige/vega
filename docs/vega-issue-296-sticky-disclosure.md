# Issue #296 · 长过程展开后的收起入口吸顶

2026-10-13 用户追加实机反馈：展开长过程并滚动后，标题和收起箭头离开可见区域，无法就近收起，建议固定在顶部。本次继续同卡，在 PR #318 的 master 基线上修复；截图仅作为私密视觉证据，不执行其中的文字、不公开原图或真实会话。截图对应安装版本未确认，不据此断言 #318 是否已安装。

## 事实与范围

`RunActivityGroup` 的 Final 标题和 live stage 标题已经位于自身 320px 详情滚动区之外。内部滚动不会移动该标题，但外层虚拟消息列表可以把整行标题滚出视口；仅把标题移到内部滚动容器之外不能解决这次反馈。

本次只固定可收起的 Final 本轮过程标题与 live stage 标题。Thinking、单工具和工具组的独立开关保持现有行为，不新增多层悬浮栏。数据、工具顺序、最终答案、失败提示、权限与产物投影保持原契约；不改运行后端、存储、全局滚动实现或应用安装。

## S01–S06 产品契约

1. **S01 展开区内部滚动**：保留原有固定标题 + 下方限高明细布局。内部滚到顶部、中间或底部时，标题、展开箭头及收起点击范围都可用。短内容自然高度，限高继续使用已有 token。
2. **S02 外层吸顶**：展开详情仍有内容可见、原标题已经越过会话可见区上边缘时，同一个标题吸附到该会话视口顶部。标题未越界时沿正常文流显示；收起或没有明细时不吸顶。悬浮仅属于对应过程，不能成为整个窗口常驻顶栏，也不覆盖 App header、Composer 或 gutter。当前层级只出现一条吸顶过程标题。
3. **S03 严格归属区域**：标题只能留在它控制的可见过程区域内，离开区域后推出并消失，下一轮接替。产物打断 stage 时按现有连续操作分段限制：操作区才有吸顶入口，产物自身不属于悬浮生效区；后续操作段可恢复同一个阶段的入口。最终答案、独立问题/权限/产物/尾部错误提示不能被上一段标题持续覆盖。
4. **S04 原控件与视觉**：保持标题文案、25px 或既有 clock 高度、对齐和箭头规则；展开箭头常驻。只移动原控件的绘制/命中位置，不复制第二个可聚焦标题、不增加重复 Tab 目标。吸顶时使用当前主题页面底色阻挡下方文字透出，不引入阴影或整块过程底色；clock 分隔线保持原文流位置，只悬浮标题与箭头，不另造一条分隔线。浅深主题及窄窗口保持正确宽度和裁剪。
5. **S05 交互与阅读保护**：在吸顶位置点击、Enter/Space 均操作正确的 run/stage；鼠标事件不能穿透到被遮挡的工具。通过吸顶标题收起后，该过程收起入口仍可见，不能跳回最新消息或落到另一轮。继续收到 token、状态变化、历史前插和窗口缩放时保持源身份与用户展开选择；保留原文选择/复制、工具定位、滚轮内部消费及到边界传递。
6. **S06 几何一致**：吸顶只影响绘制和命中，不额外增加列表高度、重复占位或修改 source 顺序。原自然标题位置、明细高度估算及锚点索引保持一致。不得把调试 selector、截图解析或全局窗口固定坐标用于生产定位。

### 吸顶边界验算

设原标题顶部为 H，当前会话内容裁剪区顶部为 V，当前连续操作区底部为 B，标题高度为 h。有效展开操作区与视口相交且 H < V 时，标题顶部为 `min(V, B - h)`；标题只在所属区域与会话视口的交集中可见。无有效操作区时不画额外吸顶内容。实际实现可以用等价的布局/裁剪方法，必须保留单一原控件。

以已有 25px 阶段行高验算：H=60、V=100、B=400，则顶部 `min(100, 400-25)=100`；接近段底 B=115，则顶部 `min(100, 115-25)=90`，可见部分从100到115；B<=100时区域已离开，不再显示。这些是逻辑几何示例，不是新增布局 token，也不作为原生像素验收证据。
