# #664 — Shell 按钮与正文选区事件边界

## 目标与范围

点击右上角环境区、底部终端、右侧面板按钮，松开后移回正文不得产生或扩展选区。保留三个按钮的启用条件、切换动作、焦点、键盘 Enter/Space 激活及正常正文拖选、跨段选择和复制。

基线：`f5891b2971a15620001e97955a0619d2b061696c`，依赖 `gpui-base 0.6.1`。静态分析发现窗口级 TextSelectionLayer 在 mouse-down 冒泡时可从正文外开始选择；shell_icon_button 在 mouse-up 截断传播，导致选择结束处理不能运行。移动处理不检查按键状态，因此残留状态可继续扩展选区。用户已报告现象，安装版本和运行时事件链尚未独立确认。

## 最小实现

仅修改 `crates/vega_ui/src/icons.rs::shell_icon_button`（调用者仅为上述三个按钮）：

1. 左键按下时初始化 GlobalState 并调用 suppress_text_selection，明确将按钮点击排除在正文选择手势外；禁用按钮同样不应启动选区。不阻止默认焦点处理。
2. 左键松开保持既有 enabled 判断与激活回调，但不调用 stop_propagation，让窗口级选区层结束拖选并复位 mouse_down_prepared。也覆盖从正文拖到按钮区域释放的手势。
3. 不修改键盘事件、面板布局/状态或正文算法，不在切换面板时主动清空选择，不升级或修改依赖，不增加全局鼠标监听。

上游的无按键移动兜底属于更广泛选区机制加固，本卡不修改依赖；先消除三个按钮造成的事件失配。
