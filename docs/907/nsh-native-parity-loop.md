## 会话复现与输入围栏

同一回环测试服务收到两个完整应用通过正常设置和 Composer 发来的请求，返回固定标题、段落、列表与 Rust 代码。第三轮候选在运行标题异步回执中 SIGABRT。加入已有的裁剪修复副本后同一操作能完成，用户气泡正文仍被挤成零宽，代码区缺原版的语言和图标。气泡应按已允许显示的正文度量，受原有最大宽度、展开/收起、复制和选区规则约束。代码标题、语言及局部复制作业应与原版匹配。

终端真实键盘聚焦还触发了 NSH 按键解析错误。原生菜单复测中，打开右键菜单时回车执行了在 shell 中预置的无害命令。菜单必须独占导航和激活事件，关闭后恢复 PTY 输入；只打开菜单不得运行、重启或写入 shell。键盘可打开菜单，复制和重启应能按名称访问。

## 空闲窗口刷新与卡顿

在同机停止输入，连续 8 次间隔 1 秒采样。第十一轮候选为 98.3%–114.2% CPU，原版隔离进程为 0.4%–2.2%。6 秒主线程采样的 444 个样本中有 415 个处于 macOS 帧回调。只给 Vega 应用层增加临时计数的构建中，稳定空窗口的一个 2 秒区间内，侧栏行重复发送 1080 个快照，收到 2160 次 AppView 通知；侧栏装饰和导航也持续发送。单个原因需要用修复后的普通生产构建同条件回测。静止时相同快照无需唤醒渲染；实际入口、权限身份、选中、焦点、主题、语言、几何、动态状态和挂载变化仍须传播。诊断计数不进入产品。
