## Authority and invalidation

`Coordinator`, `LinkPreviewService`, `open_target` and existing reading validity closures remain authoritative. NSH receives immutable presentation data, never service ownership. Every delayed NSH business command is bound to its mount identity, presentation revision, preview key/target/generation, current source-validity closure, visible occurrence and current host geometry/viewport/scale. Projection changes invalidate pending actions rather than retargeting them. Retry and address expansion are conditional on the currently observed phase/value. Every live link's captured scope scroll stamp must still match when handling commands; recycled/offscreen/unmounted source leases cannot execute. Dismissal stops the Surface and cancels the original active request. Service completions retain key/generation/cancellation/current-source checks.

NSH reports actual natural card height and measured control rectangles. Only finite, positive, bounded measurements belonging to the current presentation can update the host. Invisible GPUI focus anchors use those measured rectangles; no estimated text hit regions. Internal scroll changes refresh measurements and invalidate earlier control geometry. NSH text selection and native clipboard remain inside the NSH host.
