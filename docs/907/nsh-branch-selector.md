## Implemented presentation

- `branch_selector.rs` delegates rendering to `branch_selector/host.rs`; original controller entry points, event emission, current HEAD polling and exact pending terminal semantics remain. `current_head.rs` is unchanged.
- `host.rs` creates separate shared NSH Surfaces for the trigger and deferred window-level anchored popup. Fast paints no product labels, icons, borders, search field, rows or error text. Host-only layout preserves above/below placement, 8-point native-window fitting and the original 320/240 maximum popup size.
- `nsh_view.rs` constructs the current HEAD trigger, real NSH input, error/banner/empty/loading states, disabled create action and virtual list. The old input entity remains unrendered for public `search_input()` compatibility; both external carrier changes and NSH edits update the existing model. The original simple filter has no configured maximum; the new input likewise does not introduce a `max_length` restriction.
- Safe filtered row data is cloned into a shared immutable array only when snapshot/filter membership changes. NSH `virtual_list` materializes mounted rows; no per-frame full branch array projection or `each` over all branches. Keyboard focus positions are computed on focus/filter changes, not scanned every frame. Row height remains `BRANCH_ROW_HEIGHT`; search plus spacing, separator and disabled action still sum to `BRANCH_CHROME_HEIGHT`.
- Commands use OrderedCommands. Pointer actions bind the actual row snapshot, opaque BranchId and mounted row lease. Receivers compare page/revision identity, route, generation, pending tuple, status, current/visual candidate, environment and freshest controller state. Hidden/unmounted hosts reject through retained-element mount leases and clipped bounds. Draft writes also require their exact live popup identity. Render acknowledgements prevent host keys from borrowing a not-yet-rendered projection.
- A real paint-free focused ancestor handles original actions, Up/Down/Enter/Escape and Tab. Up/Down transfers native input focus to the list host; Tab enters the input, Shift-Tab returns to the host, and reading-order boundaries close the menu and leave to the external window chain. Child AppViews are not duplicate native Tab stops. The native marked-text range and shared composition state guard activation for keyboard, pointer and AX paths. Virtual reveal uses measured list viewport/scroll offsets and fixed row height; a measured mounted row supplies the paint-free active-descendant proxy.
- Engine failure replaces only the affected rendering with a fresh NSH Reload control. Explicit Reload recreates presentation only, preserving model and pending state and emitting no list or switch request. Service retry remains close/reopen. If even this recovery surface cannot start, native keyboard recovery is the available path; there is deliberately no legacy painted fallback.
