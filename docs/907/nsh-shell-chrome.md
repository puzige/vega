- Main title, update Available/Ready labels and navigation error text remain exact, with shared typography, colors and original shell geometry. Existing NSH navigation controls remain wired.
- Each enabled control has native Tab focus, visible NSH focus, Enter/Space activation and an accessible name; disabled controls retain real state and never mutate business state.
- Pointer, native keyboard and AX use the same trusted dispatcher and original controller methods. Recheck exact current thread/project, updater phase/dismissal, workspace availability/selection and current presentation identity. Settings, modal/palette obstruction, inactive window, hidden/dropped mount, failed surface and obsolete geometry reject queued actions.
- Layout acknowledgements identify the exact published frame; stale acknowledgements do not authorize replacement state. Native clipped bounds must contain the selected control and match the current viewport/scale. Consume action authority before invoking an original operation; never replay it on rebuild.
- Presentation failure cannot cause updater installation, retry business operations or expose visible legacy controls. Preserve failure as a validation limitation rather than claim a failed engine can paint a recovery UI.
- Headless regressions verify projection invalidation and displayed-action authority; local compilation/Clippy and existing regressions plus independent review validate integration. Native focus/AX/compositor pixels and three-platform interaction remain user acceptance, not inferred from headless checks.
