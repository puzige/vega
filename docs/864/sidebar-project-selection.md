# 侧栏项目选择与折叠解耦

关联 #864。基线 f7cd2aabf4bd84326f3f868f4ddd4288d2cf96ea。

## 范围与证据

点击项目行目前同步写最近打开时间，可能等待全库写入许可；现场尚未捕获阻塞瞬间。本卡起初只改侧栏项目选择链。2026-11-03 用户追加置顶卡顿并明确选择纳入当前修复：置顶同样经 UI 回调同步获取全库写许可。范围追加置顶/取消置顶，不改数据库结构、用户运行时数据、全局写入协调、归档或其他同步写入。

## 行为契约

- 两种组织视图中，项目名称/行主体负责选择项目，文件夹图标为独立展开/收起按钮。Enter/Space 与鼠标语义一致，子按钮停止冒泡，保留无障碍名称与展开状态。折叠不触发导航、最近打开时间写入或草稿离开校验。
- 选择立即更新 SelectedProject 并发出 Selected；后台串行更新最近打开时间。待处理选择合并为最后一次，避免无界后台写队列及旧选择晚写。
- 数据库打开、写许可等待、UPDATE 和项目重新读取均不得在选择回调的 UI 主线程执行。持久化失败不回滚用户的新选择，显示现有项目错误入口，可通过重新选择重试。
- 完成回投只接受相同请求代次、数据库路径、当前项目且项目仍存在的结果。旧请求不能覆盖新路由或发布旧列表。成功后后台刷新项目与组织快照；失败不伪装成功，不被本请求的刷新擦除。
- 本卡不新增常驻说明文案或成功提示，不增加依赖版本或改变权限边界。

## 置顶增量契约

- 置顶与取消置顶使用同一后台入口：打开已有数据库、等待写许可、写入和读取真实状态均在后台，UI 回调立即返回；不改为乐观伪成功。
- 沿用任务变更围栏，保存期间重复置顶或冲突变更拒绝执行；目标按钮呈真实局部等待态。全局围栏即使所属视图释放也必须在 worker 完成后释放。
- 成功后以实际持久化状态更新目标行与组织快照，必要刷新仍走后台；不得改变当前路由。失败保留原置顶状态并显示可重试错误。数据库切换后旧结果不应用，离开原路由后旧失败不覆盖当前错误。
- 回归覆盖写许可被占用时回调立即返回、置顶/取消置顶成功、失败后重试、重复操作不产生第二次变更、旧数据库回投及视图释放后围栏回收。只用隔离临时数据库，在 Actions 执行；鼠标/键盘真实交互仍待用户手测。

## 验证

开发分支增加行为回归：选择即时反馈、后台成功/失败、连续选择仅接受最新结果、移除后的旧结果、独立折叠不选择。必要存储验证只用隔离临时数据库，不访问用户数据库。自动测试交 Actions，本地仅格式与静态检查。

按仓库政策，开发 Rust 测试及独占依赖/接线在留存完整源码 SHA 和实际云端结果后移除；最终 head 再跑完整 required CI，并由非实现写入者审查。合并后用户手测转圈场景、两种视图的鼠标/键盘选择折叠、快速切换与失败恢复。CI 不代表真实系统验收。
