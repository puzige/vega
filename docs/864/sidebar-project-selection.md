## 行为契约

- 两种组织视图中，项目名称/行主体负责选择项目，文件夹图标为独立展开/收起按钮。Enter/Space 与鼠标语义一致，子按钮停止冒泡，保留无障碍名称与展开状态。折叠不触发导航、最近打开时间写入或草稿离开校验。
- 选择立即更新 SelectedProject 并发出 Selected；后台串行更新最近打开时间。待处理选择合并为最后一次，避免无界后台写队列及旧选择晚写。
- 数据库打开、写许可等待、UPDATE 和项目重新读取均不得在选择回调的 UI 主线程执行。持久化失败不回滚用户的新选择，显示现有项目错误入口，可通过重新选择重试。
- 完成回投只接受相同请求代次、数据库路径、当前项目且项目仍存在的结果。旧请求不能覆盖新路由或发布旧列表。成功后后台刷新项目与组织快照；失败不伪装成功，不被本请求的刷新擦除。
- 本卡不新增常驻说明文案或成功提示，不增加依赖版本或改变权限边界。

## 置顶增量契约

- 置顶与取消置顶使用同一后台入口：打开已有数据库、等待写许可、写入和读取真实状态均在后台，UI 回调立即返回；不改为乐观伪成功。
- 沿用任务变更围栏，保存期间重复置顶或冲突变更拒绝执行；目标按钮呈真实局部等待态。全局围栏即使所属视图释放也必须在 worker 完成后释放。
- 成功后以实际持久化状态更新目标行与组织快照，必要刷新仍走后台；不得改变当前路由。失败保留原置顶状态并显示可重试错误。数据库切换后旧结果不应用，离开原路由后旧失败不覆盖当前错误。
- 回归覆盖写许可被占用时回调立即返回、置顶/取消置顶成功、失败后重试、重复操作不产生第二次变更、旧数据库回投及视图释放后围栏回收。只用隔离临时数据库，在 Actions 执行；鼠标/键盘真实交互仍待用户手测。

## 全部审计项分批修复（用户追加授权）

用户明确要求按清单修复剩余同步写库与配置落盘，补齐锁竞争、失败重试及旧结果隔离，独立审查后合并。实施起点 `97e313e665e7f015980ead0da588a9e7843e3b7f`，保留此前项目选择与置顶实现及证据。

### A：会话状态与已读

- 归档/恢复、标为已读/未读的数据库打开、原服务安全检查、事务、自动化暂停和真实结果读取整体在后台。UI 即时返回，使用既有任务变更围栏拒绝重复/冲突提交；保持原状态直到持久化成功。
- 成功更新目标行、打开会话及组织快照，不触发导航；归档仍遵守运行任务约束和原事务语义。失败保留原状态并可再次操作重试。刷新不得在 UI 回调重读数据库。
- 捕获数据库与路由代次；数据库已切换则不应用旧结果，离开路由后旧失败不覆盖当前错误。视图释放后仍释放全局围栏。

### B：删除、项目移除与导航访问

- 删除保留子任务存活、访问许可和预计算清理检查；移除保留“解绑会话而非删除会话”事务及运行任务/离开草稿校验。全部服务操作移入后台，成功后才发送删除/移除事件或清除相应状态，失败保持可重试入口。
- 结果只应用于原数据库；对当前路由的清理必须仍匹配被操作对象，不能把新打开对象清空。列表刷新在后台，视图销毁仍回收变更围栏。
- 项目移除与所有项目 worker 注册共用应用级准入，移除等待共享写许可期间禁止同项目新 worker；已有 worker 则拒绝移除。失败释放准入允许重试，成功后旧项目身份不再接受 worker。
- 项目移除结果绑定完整路由及代次，包括设置页离开再返回；普通列表刷新成功不能擦除未解决的操作错误，实际操作重试成功才清除。写入完成后的组织快照刷新也必须校验数据库身份，旧库成功和失败均不发布。
- 历史导航共用访问记录服务异步执行，保留更新时间、项目访问和清未读语义；共享调用方（搜索/通知）一并使用该入口。不阻塞 UI，旧数据库/路由/代次结果不得覆盖新页面或错误；失败保留导航并提供现有错误及重新访问重试。

### C：侧栏配置偏好

- 显隐、宽度提交、旧分块折叠及注册后的显示侧栏仅即时更新内存；配置路径解析、互斥等待、YAML 读改写、原子发布和 fsync 全在后台。
- 单在途、按字段合并最新待保存值；每次后台提交以最新磁盘文档为基础只变更侧栏字段，保留其他配置字段、原样 YAML 更新、权限及冲突校验，不用旧完整配置覆盖。
- 失败保留未保存补丁和可见错误，提供明确重试；旧批次不得清除新批次错误或覆盖新内存偏好。配置身份变更后的完成不能应用旧状态。
