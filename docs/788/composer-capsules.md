# Composer 模型与权限胶囊

## 来源、范围与替代关系

用户最新明确裁决：模型和权限按钮统一 `rounded_full()`，高度调到 32，其他样式保持不变。基线 `8c5f4148c25d0b12298bbecfb0e4a7a121c3fae3`，分支 `feat/788-composer-capsules`，关联 [#788](https://github.com/puzige/vega/issues/788)。

本规格只取代 [#546](../546/vega-issue-546-capsule-state-correction.md) 中这两个触发器的 28 高、14 固定圆角、28 最小宽度；状态与业务契约继续有效。其他相关按钮只做静态分类建议，不在本轮改造；不引用第三方解包资产作为设计输入。

## 验收与最小实现

- `COMPOSER_TEXT_TRIGGER_HEIGHT` 从 28 改为 32；模型和权限的高度、最小宽度均继续引用它。
- 两处触发器改为 `.rounded_full()`，删除无消费者的 `COMPOSER_TEXT_TRIGGER_RADIUS`。
- 保留模型 `SIDEBAR`、权限 `BODY` 字号（当前都为 13），左右内距 12、图标与间距、标签预留宽度与截断、文字及权限警示色。
- 默认透明，hover 为 `bg_hover`，按下及菜单展开为 `bg_active`，禁用 gating、焦点、鼠标键盘、外部关闭、模型保存及权限 guard 不变。
- 不改全局交互助手、发送/停止、加号、utility bar、排队及问答按钮；不新增界面文字、阴影、边框、动画、依赖或密度变体。

## 几何核算与回归

| 项目 | 旧值 | 新值 |
|---|---|---|
| 高度与最小宽度 | 28 | 32 |
| 胶囊实际圆角（宽度不小于高度） | 14 | 32 / 2 = 16 |
| 13 字号、1.55 行高的名义剩余空间 | 28 - 20.15 = 7.85 | 32 - 20.15 = 11.85 |
| 名义单侧垂直余量 | 3.925 | 5.925 |
| 左右内距 | 12 / 12 | 12 / 12 |

GPUI `rounded_full()` 表达全圆角，实际半径按短边一半钳制，不再维护高度/半径配对。上下余量是名义行盒算术，不冒充真实字形或像素测量。底栏 `items_center` 保持垂直居中；窄窗口和长模型名仍需核对入口可达、截断、主动作不重叠。

## 验证与回滚

本轮为两处共享几何调整，不为流程创建临时 Rust 测试。本地只做格式、差异和消费者静态检查，不运行 Vega、编译、构建、打包或测试。非实现者独立审查和最终 head 现有 required CI 均完成后才合并；编译/测试发现与执行结果以 Actions 为准。

用户手测：浅深色、默认/hover/按下/展开/关闭/禁用、Tab/Enter/Space/Escape、模型切换保存、四种权限、长标签与窄窗口、发送/停止及弹层锚点。真实外观和系统集成未手测前不得声称通过，Issue 保持开放。

回滚仅恢复共享高度 28、固定半径 token 14 和两处圆角调用；无持久化或安全策略变化。
