# 恢复用户消息气泡行高

## 范围与基线

用户反馈多行用户气泡行距明显收紧，并授权修复。基线 `632a5a2e554cecadb06d2a9bfa53e5fc3d6730a2`；分支 `fix/user-bubble-line-height`。#810 引入用户专用行高 `(13.5 + 4) / 13.5`，正文由 23px 变为 17.5px；#815 的图片时间对齐未改文字行高。

## 修订契约与最小实现

- 普通用户正文恢复原有 23px 行高，字号仍为 13.5px。`Typography::CONVERSATION_USER_LINE_HEIGHT` 引用 `CONVERSATION_LINE_HEIGHT`，避免相同标准漂移。
- `render_rows` 气泡容器、Markdown 文本、`user_disclosure` 预览/表格测量、20 行阈值与 19 行预览、省略号以及 `message_anchors` 估算继续使用同一用户 token，无重复像素覆盖。
- 保留气泡配色、22px 圆角、16px 横向和 10px 纵向内距、Markdown 层级/段落规则、长消息展开交互、图片时间/附件布局及复制/焦点行为。不调整助手、代码块、全局字体或消息时间分组。
- 本契约替代 #804 的“字号 + 4px”普通正文行高要求，其他契约不变。

单常量排版修订：本地仅格式、差异与消费者静态核查，非实现者独立审查及最终 required CI；不为常量相等编写镜像/源码字符串测试，无新增 Rust 测试、依赖或 CI 变更。本地不运行 Vega、编译、Clippy 或测试。
