# MCP 参数输入与不可用提示修订

## 范围与验收

依据用户截图反馈，修正 MCP 参数无法按 Enter 换行及 composer 下方的警告卡片。不改变 MCP 连接、安全、凭据或工具选择策略。

- MCP 本地参数和环境变量声明输入框支持 Enter 插入换行，粘贴和保存仍按每行一个值处理；单行字段不插入换行，Tab 导航与按钮激活不变。
- MCP 不可用属于本轮工具准备告警，不表示整个回合失败。提示移至 composer 上方的既有准备错误区域，使用无背景、无边框、可换行的红色文字，不再占用 composer 下方。
- 保留不可用数量、工具被排除的影响和设置 → MCP 的恢复指引；不暴露远端原始错误或凭据。不改变下一次提交清理告警的生命周期。
- 无告警时不留占位。中英文与浅深色均沿用现有本地化和主题 token。

## 实现与验证

MCP Settings 根上下文缺少 Enter → InsertNewline 绑定，而多行 TextInput 已有换行处理；为该设置上下文补齐绑定。提示复用既有 plain_error_notice，并与 composer 上方的准备错误处于同一层级。

本地仅差异、格式与静态检查，不运行 Vega、不编译、不测试。云端 required PR check 验证最终版本；真实键盘输入、保存重开及告警视觉由用户手测。
