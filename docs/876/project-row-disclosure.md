# 项目整行展开/收起与紧凑图标间距

关联 #876。基线 `3cf6573b9fdbcbf59de9d5ba3b46defab836401f`。

## 用户裁决与范围

用户反馈项目名称点击不能收起、文件夹与名称间距过大，并提供 ChatGPT 可见界面参考。用户已明确选择：项目整行只切换展开/收起，不切换当前会话。此裁决替代 [#864 行为契约第一条](../864/sidebar-project-selection.md#行为契约) 中名称选择项目、独立图标折叠的规则；其后台写入、安全及数据隔离规则不变。

仅修改两种组织视图的项目行事件与图标布局，不改导航、数据库、后台调度、全局 Projects 分组标题或独立项目管理列表。

## 根因与最小实现

`organization/render.rs` 和 `organization/projections.rs` 的行主体目前发送 `Control::Project`，调用项目选择；独立 `project_disclosure` 图标按钮发送 `ToggleProject`。图标按钮宽 32px、图标 16px，外层另有 8px gap，使图标右缘与名称之间变为 16px，且图标整体右移。

移除项目行的选择分发和独立图标按钮；两种视图的整行鼠标及 Enter/Space 都发送现有 `ToggleProject`。保留整行 32px 点击区，直接渲染共享 16px Folder/FolderOpen 图标，保留原有 8px gap、外侧 inset、任务缩进和动作槽。展开状态放在整行 Button 的 `aria_expanded` 上，保留项目名称与 focus-visible。

## 验收与回归边界

- 点击图标、名称、可用行内空白，每次只切换该项目一次；展开显示任务、收起隐藏任务，再次点击可重新展开。
- Enter/Space 与鼠标一致，项目行只有一个折叠焦点入口；读屏能获得项目名与展开状态。
- 折叠不改变当前会话、SelectedProject 或草稿，不进入导航拦截或最近访问写入。
- 右侧新建与菜单保留独立动作并停止冒泡；右键菜单、拖拽排序与拖拽释放保护不变。
- 图标 16px、名称间距 8px、行高 32px；窄窗截断、选中/hover/focus 与浅深色保持既有 token。
- 保留现有折叠持久化入口与错误处理，不新增常驻说明或成功提示。
