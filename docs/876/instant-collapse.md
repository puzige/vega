# 即时展开/收起与最小持久化

关联 #876；基线 `9d3803dadcf30149a55fad116501c815651c3d07`。用户在只读调用链审计后授权按优先顺序实施四项优化。本规格取代原规格中只保留通用组织保存路径的限制，不改变整行折叠、导航隔离和视觉几何契约。

## 验收与实现顺序

1. 普通项目点击不复制/排序全任务列表。拖拽投影只在真正开始拖拽时建立；保留任务排序和拖拽释放抑制。
2. 折叠回投只应用 revision/collapsed，不重新统计或复制任务。渲染共享快照，缓存按任务/偏好实际内容失效的排序投影，折叠不重复全量排序/计数/焦点集合构建。保留渐进列表、可见任务内容、置顶和归档实时更新。
3. 点击和 Enter/Space 同步更新本地 collapsed，通知下一帧，不等 I/O，不因组织保存或任务变更围栏拒绝折叠。每个目标保存最新意图，单一在途批次，后续点击合并；保存和通用组织请求串行，避免旧快照覆盖新意图。保存成功仅确认对应批次，较新点击仍优先；失败仅回退没有较新意图的目标到最新已知持久状态，显示可操作错误并允许再次点击重试。旧失败不能回退新意图或清除其他错误。切库清空该库本地意图并递增围栏，取消旧保存任务；旧任务获得写许可后和提交前复查取消，防止 A→B→A 时旧写入晚于新写入。旧库/旧代回投忽略，项目删除后的结果不复活项目。
4. 专用 collapse 保存只读 revision/collapsed、校验目标存在并更新这两个字段；在即时事务内对最新 persisted collapsed 合并目标变化，避免覆盖其他目标并保留其他组织字段。仍使用共享写许可，不绕过锁、安全校验或错误；全在后台。返回轻量 revision/collapsed，不读完整任务快照，不改 sort、groups、memberships、project_order。

## 状态与错误生命周期

UI 展示的是持久状态叠加最新本地意图，不把即时反馈称为保存成功。失败提示包含重试方向，保留到对应重试成功；普通刷新不能擦除错误。重试通过再次操作该项目；无无限自动重试或无界点击队列。保存成功不新增提示。现有任务/组织错误与折叠错误分离，旧结果不得覆盖当前路由错误。切库、视图销毁、刷新和通用组织动作并发均须隔离。正常成功后重启保持最终值。

## 回归与验证

开发测试覆盖：数据库写许可占用时本地立即切换且工作未完成；快速偶数/奇数次和多项目切换最终值；在途成功/失败后新意图优先；最新失败回退与重试；旧库旧代回投忽略；刷新与通用组织动作不覆盖本地意图；删除项目后不复活；专用事务不改变排序/分组/成员/项目序，不读任务集合；拖拽仍可正确提交，普通点击不准备排序投影；投影缓存数据变化正确失效。

本地只做 diff/fmt/静态检查，不运行代码/测试或编译。行为验证只交现有 Actions，隔离临时数据库，不接触用户数据。开发 Rust 测试须固定可恢复完整 SHA、源码与云端实际结果后单独清理；最终无测试 head 再跑完整 required CI，非实现者独立审查后合并。原生时延、鼠标/键盘/拖拽、窄窗/主题与真实存储失败仍由用户手测。没有现场测量不承诺固定毫秒预算；验收是无同步 I/O/写锁等待、先本地生效再后台保存和有界计算/队列。

非目标：不更改全局写入协调、数据库 schema、其他侧栏写操作、发布流程或用户配置，不恢复旧测试集合。回滚撤销本卡生产改动，不修改用户数据。
