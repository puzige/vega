# Issue #78 — 用户消息气泡

来源：https://github.com/puzige/vega/issues/78 。仅以用户提供截图的可见布局为参考，不复制截图正文或第三方内部实现。

## 范围与契约

当前 `user_message_item` 使用整列卡片和「你」标签。改为用户文字消息右对齐、短消息随内容收缩、长消息自动换行的圆角气泡；助手正文继续左对齐。仅改变呈现，不改变发送、历史数据、流式处理或消息顺序。

- 气泡背景使用现有 `brand_soft`，正文使用 `text_primary`，自动适配浅深色。
- 移除可见的「你」标签。保留内部行模型兼容性，无数据迁移。
- 气泡最大宽度为可用消息列的 80%，短消息不铺满该宽度；以类型化 Layout token 表达比例和圆角（16px），内边距水平 12px、垂直 8px。
- 消息列最大 768px，因此气泡最大 614.4px，扣除左右内边距后文字宽度最大 590.4px；实际更窄时按可用列宽同比约束。圆角由 GPUI 按实际尺寸钳制。
- 保留多行、内部空行、CJK/Latin 混排与长无空格字符串的完整可读性，不省略、不截断。
- 用户图片沿消息列右对齐，保留现有缩略图、换行及交互；不把助手、工具、思考或错误卡片装入气泡。
- 空会话、助手错误提示、历史恢复与正在流式输出的行为保持既有契约。
