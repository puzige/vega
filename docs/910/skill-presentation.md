# Skill 信息展示

## 授权与范围

用户要求：不影响用户判断或操作的 Skill 信息不展示；确需展示时统一复用工具活动行。保留内部审计和验证。基线 d4beacac2f01d4c09af7545163393e9d43753fe9。

## 验收（先于实施）

| 场景 | 可观察结果 | 验证 |
|---|---|---|
| 重开含已验证、未验证或已撤权 Skill 审计的历史 | 不生成审计行、合成成功工具行、额外分组或留白 | 历史预处理回归 + 静态接线 |
| 仅收到 SkillActivated 通知 | 不额外生成 UI 项；真实工具调用仍独立处理 | 静态事件分支检查 |
| 真实 load_skill / read_skill_resource 调用 | 继续走现有 ToolCard 与工具活动组，不增加专用组件 | 工具投影与状态回归 |
| 加载失败、拒绝、取消、损坏记录 | 真实结果仍在工具活动行可见，不能被审计记录改成成功 | 工具状态回归 |
| 历史正文与其他工具项 | 内容、顺序、时间边界保持；审计不形成额外活动组 | 历史预处理回归 |
| 审计与验证 | Store / conversation / runtime 逻辑与持久记录不改 | 差异核对 |

## 实现计划

1. 在 UI 历史预处理入口丢弃仅供内部追溯的 SkillActivation 投影；不修改上游审计或验证结果。
2. 删除 UI 专用 SkillActivation 流条目与渲染、锚点、时间戳接线，避免空白占位。
3. 实时 SkillActivated 通知不再合成成功工具行；保留真实 ToolCall 的全部状态与普通活动行。
4. 删除只供合成展示的构造与去重方法，不修改普通 ToolCard 的行为。
5. 开发 Rust 回归仅由 Actions 执行；固定可恢复源码和实际证据，合并前清理。最终 head required CI 与非实现者独立审查必须完成。

## 展示取舍

真实工具调用本身仍作为任务执行记录展示；不因单纯审计或激活通知重复展示。无当前影响的历史快照不可用/未验证/撤权信息保持内部，不推断当前任务受阻。实际工具错误不隐藏；本卡不新增错误判断或改写模型回答。必要提示使用既有工具行，不另造底栏、卡片或历史状态条。

## 非目标与限制

不处理 #783 的持久化一致性协议；不修改 Skill 加载、权限、撤权、来源、SHA、资源冻结、设置或用户 Skill 文件。不新增依赖，不本地运行 Vega、构建或测试。原生像素、键盘和真实会话手测由用户完成。
