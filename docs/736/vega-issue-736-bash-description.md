## 数据与安全契约

- 模型 schema 新增可选 string `description`，maxLength 200；提示主动语态、一句话、跟随用户语言，简单命令使用 5–10 个词。
- 解析接受缺失或字符串（包括空白和超过 schema 建议长度的字符串）；其他类型作为非法输入拒绝，其他未知字段仍拒绝。运行时不因长度拒绝合法命令，展示层负责限长。
- `PreparedBash` 单独保存描述；权限签名、执行输入 `input_json()` 和语义比较均忽略描述。command、timeout、requested_scope 的现有语义不变，legacy cmd/timeout_ms 兼容不变。
- 安全投影仅保留 command 和净化后的可选描述，不传原始 JSON。描述中控制字符、Unicode 换行分隔符折为空格，trim 后按 Unicode 字符截到 120；纯空白视为缺失。描述为纯文本，不解析 Markdown 或链接，不写入命令日志字段。

## 展示契约

| 状态 | 有描述 | 无描述 |
| --- | --- | --- |
| 成功、运行中、已批准 | 描述原文（经净化） | 原有标题 |
| 等待批准、失败、取消、拒绝、接管后未执行 | 本地化状态 · 描述 | 原有标题 |
