### 最新截图修订：展开时切换标题

同轮追加裁决：工具调用与 Thinking 过程模块的产品界面文案统一英文，不能翻译或改写模型生成的思考正文/标题、用户内容、命令和工具输出。英文覆盖工具卡、工具组、工具权限卡、会话内 Skill 激活/历史条、阶段/Thinking 控件的状态、动作、提示与可访问标签（权限语义不变，danger_reason 等原文保留）；无关全局设置/会话界面不扩范围。

展开命令标题不用中点：成功 `Ran command in 3s`，运行 `Running command for 0s`，失败 `Command failed after 3s`；无真实时间时分别省略时间短语。取消/拒绝/待批准准确英文状态。耗时使用紧凑英文单位（ms/s/m/h），持续来源不变。收起标题例如 `Ran echo hello`，不带耗时；原箭头交互不变。工具/Thinking 模块英文测试需覆盖无模型内容被翻译、状态/权限错误不丢失，以及原有计时、展开、隐私断言。

2026-10-15 用户补充 Codex 收起/展开截图，覆盖下文耗时始终行内显示的旧约定。Shell 收起时标题显示实际命令，长命令单行省略，不展示耗时；展开时标题替换为简短状态与真实耗时（例如 `Ran command in 3s`），完整命令仅在下方 Shell 详情中展示，不能在标题重复。

运行中展开标题为 `Running command for 0s`，真实执行开始后按原时钟更新；批准前与历史缺失起点不编造时间。失败/取消/拒绝保持准确状态；已完成历史按存储 duration_ms 展示。收起再次恢复实际命令，隐藏行内时长，不能丢失计时状态。

原箭头显隐、hover/focus、鼠标/键盘切换、自动展开与历史恢复全部通过同一展示投影切换标题，不能仅在一种点击处理器更新。详情右下角图标加 Success/Failure、完整输出、诊断、隐私和整体 Worked for 不变。

实现前验收：真实状态矩阵的收起/展开标题；运行0/1/65秒及终态冻结，缺失历史时间；鼠标、键盘和程序自动展开/收起的一致性；长命令收起省略、展开完整命令且标题简短，耗时/箭头不溢出；保留footer、安全及滚动回归。本地仅fmt/diff，测试交给CI。

### 用户手测修订：标题右侧时间与简短结果

2026-10-15 用户确认：命令标题左侧显示命令详情，耗时固定在整行最右侧；长命令单行省略，不得挤掉耗时。展开保留完整命令和输出。成功/失败的详情底部只显示 `Success` / `Failure`，不重复显示“已完成”、exit 或耗时。此修订覆盖下文旧的详情底部耗时约定；回合整体 Worked for 时间不变。

耗时沿用真实运行时钟与结果 duration_ms；批准前和缺失历史时间不编造数值。耗时为不收缩的尾部槽位，命令使用剩余空间，折叠箭头保留可发现性和键盘入口。拒绝、取消、等待等非成功/失败状态保留准确状态，不能误标 Success。输出及其截断标记、失败诊断和底层元数据不改写。

用户继续确认：成功使用共享勾图标加 Success，失败使用共享叉图标加 Failure；状态行位于展开详情滚动内容的末尾、右下角，不能移到滚动块外。图标和文字同时表达结果，失败保留 danger 语义；不使用 Unicode 字符替代图标。验收补充成功/失败图标、末尾位置及右对齐，保留输出滚动。

实现前验收：成功和非零退出分别只显示 Success/Failure；运行 0/1/65 秒、不同工具独立计时、终态停止及历史无时长均覆盖；短/长命令及窄宽窗口的时间右对齐、命令单行、无重叠由 GPUI 几何断言覆盖；完整命令、折叠/焦点、失败颜色及隐私断言保持。只改工具卡与相关 UI 测试，编译及测试交给 CI，本地仅 fmt/diff。

用户报告简单 Shell 命令出现毫秒级 exit -1 且无输出。原实现将无退出码的进程状态映射为 -1；以下结论基于系统崩溃记录与最小复现，不凭截图认定成功或解析错误。

修复 Shell 启动/结果诊断的实际缺陷，保留权限、凭据隔离、进程组取消及输出脱敏。不得通过移除安全边界让命令成功。历史 -1 不编造具体信号；新运行应提供可验证失败原因。

已定位：系统崩溃报告的父进程为 Vega，zsh 因 libdispatch 无法读取 unique pid 触发 SIGTRAP。最小无害 probe 证实 deny process-info* 可复现，增加仅作用于自身的 process-info-pidinfo 例外后恢复。实现保留全局 deny，仅 allow process-info-pidinfo (target self)，其他进程及其他信息类型仍受限。启动 stderr 与 stdout 纳入同一有界输出收集，保留取消与 EOF 处理；信号退出在输出中追加真实信号信息，保留既有 -1 元数据格式和历史兼容，不增加存储字段。

工具过程以用户提供的 Codex 截图为可见参考：页面同底、紧凑单行、语义图标、动作加对象（命令显示实际命令，读取显示文件名），长标题单行省略，展开才能查看完整内容。分组使用活动描述而非 Commands 等泛称。命令失败必须保留可见失败状态和操作对象。默认列表不堆叠 exit、耗时等元信息。保留 Vega 原有最终运行时间与命令详情底部耗时设计，不修改计时数据来源。

详情按需展开，保留现有浅底边框输出区域、完整命令、真实输出及终态 footer。保留原有授权与错误入口、键盘折叠、焦点、选择复制、浅深主题及阅读位置。用户/模型正文不改写；不因工具 UI 调整移除真实思考内容。不得复制私有实现或解包资产。

## 验收矩阵（实现前）

| 用例 | 操作与预期 | 验证 |
|---|---|---|
| 正常执行 | 命令成功结果保留输出与 exit 0，标题包含实际命令 | 进程内回归，CI |
| 异常退出 | 信号终止与普通非零退出可区分，不伪造成功；无输出不掩盖已知错误 | 进程内回归，CI；系统手测 |
| 安全 | 凭据保护、sandbox、取消、超时行为不削弱 | 既有与定向回归，CI |
| 列表 | Shell 命令与读取文件名可识别；搜索及混合分组显示安全动作摘要，长命令省略 | GPUI/投影回归，CI；用户外观手测 |
| 折叠 | 默认/展开/收起、键盘、失败、授权状态保留；详情可读 | GPUI 回归，CI |
| 时间 | 最终运行时间与命令详情底部时间仍由原数据驱动 | 定向回归，CI |
| 恢复 | 已存结果与历史 -1 可恢复，不假定未知信号 | 投影回归，CI |

## 实现归属

主 agent：规格、证据、review、集成、PR 与 CI。

Shell executor：vega_tools 的 bash/sandbox/output 及对应测试；必要的 runtime/conversation 错误传递修改先报告接口。

UI executor：vega_ui 工具卡、工具组、run_activity 与相关测试；如需几何 token 可修改 vega_theme。允许最小扩展 vega_conversation 的 ReadOnly 安全输入投影以携带读取文件名，保留输入校验、脱敏和旧历史兼容，UI 不直接解析原始输入。不能修改 Shell executor 文件。

CI 审查修订：既有隐私回归明确禁止 Glob/Grep 原始查询词与目录进入工具 UI；本轮不扩大此边界。ReadOnly 新展示字段仅用于 Read 文件名，Glob/Grep 保持动作类别摘要。命令使用既有 Bash 展示投影，不新增数据访问。搜索对象扩展计划已撤回，安全断言不删减。

本地只运行格式和静态差异检查，不编译、测试或打包。CI 使用仓库 pr-check。真实外观与外部进程由用户在合并后手测。执行者分别提供 docs/vega-tool-block-shell-delivery.md 和 docs/vega-tool-block-ui-delivery.md，明确已验证与待验证。
