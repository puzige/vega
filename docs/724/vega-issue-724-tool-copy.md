# Shell 工具详情双复制按钮

## 目标与边界

对应 #724；基线 `821182b1`，沿用 Issue 中已确认方案。仅原生 Bash/Shell 详情增加 Copy command / Copy output，不改折叠标题、执行流程、权限、持久化、安全投影和其他工具的复制语义。

## 实现契约

- `ToolCard::detail()` 的命令保留输入安全投影原文，渲染时才添加 `$ `；输出复制源取 Bash 结果安全投影原始字符串，不由 `.lines()` 的展示行重建。
- `render_detail()` 将命令、输出分别放入横向区域，文字占可收缩剩余宽度，右侧复制按钮固定占位且顶对齐，不覆盖文字或滚动条。沿用详情最大高度、滚动与共享布局/主题 token。
- 按用户反馈修订：按钮默认隐藏，仅鼠标 hover 对应命令区/输出区时显示，两个区域独立；鼠标离开后隐藏，键盘焦点在按钮上时仍显示。保留固定占位，不因显隐改变文字宽度或布局；不因回执激活而让离开区域的按钮常驻。
- 命令非空时可复制；输出仅在已保留非空 Bash 结果时可复制。空输出和运行中无结果不提供输出按钮；失败输出仍可复制；截断输出只复制已保留内容并保留现有截断标识。
- 不复制 Shell 标题、摘要、提示符、执行状态和无输出占位。不读取原始工具 JSON 或新增后端接口。
- 通过 `conversation_stream` 的窄共享入口复用 `CopyReceiptButton`。工具文本源以内容相等判断是否仍为同一源，避免重绘重新分配文本导致回执消失；内容变化清除回执。既有消息/代码的来源判断保持不变。
- 两个控件使用详情卡片身份和动作组成的独立 ID，沿用约 1 秒勾选回执、卸载清理、tooltip、Tab 和 Enter/Space、无障碍 Click。工具文本使用原生 click 手势：按下与释放同属按钮才复制，mouse-up 不截断，使从正文拖到按钮松开的选区仍能结束；详情与折叠标题互为兄弟，不修改消息/代码按钮原有事件处理。
- 新文案只有 `ui.copy_command` / `ui.copy_output` 的中英文动作名称，不增加说明段或成功 toast。

## 修改位置

1. `crates/vega_ui/src/tool_card.rs`：区分命令展示与复制原文、输出原文，添加区域布局与复制控件。
2. `crates/vega_ui/src/conversation_stream/copy_receipt.rs`、`mod.rs`：新增受限的纯文本构造入口，复用现有生命周期，不改消息/代码入口。
3. `crates/vega_i18n/locales/ui.en.toml`、`ui.zh-CN.toml`：新增两项动作标签。

## 验证策略

本次为 UI 布局与现有复制组件接线，不新增 Rust 开发测试或恢复历史集合。静态核对安全投影、原文换行、来源身份、无结果/空结果/失败/截断分支、事件传播与按钮布局；本地只运行格式和差异检查。最新 head 由现有 Actions 执行 fmt、全目标 Clippy、Python 回归和 Rust 空集门禁；`no Rust tests` 不是行为测试通过。实现由非写入者独立审查。真实 GPUI 焦点、布局及系统剪贴板交用户在合并后手测，静态与 CI 不替代该验收。

## 用户手测清单

- 展开 Shell 后按钮默认隐藏；hover 命令区只显示 Copy command，hover 输出区只显示 Copy output；离开区域隐藏，移入按钮仍保持显示。显隐不造成文字跳动，收起标题不增加按钮。
- 无鼠标 hover 时 Tab/Shift-Tab 聚焦对应按钮仍显示焦点与复制动作；离焦后恢复隐藏。
- 多行命令、here-document、Unicode、引号及缩进逐字一致，不带 `$ `。
- 输出保留空行、CRLF/末尾换行和缩进，无标题、状态或占位；失败输出可复制，空输出不覆盖剪贴板，截断提示仍在。
- 连续点击两个按钮，回执独立且约 1 秒复原；重绘不提前消失，内容变化或折叠再展开不遗留旧回执，多卡不串内容。
- 长输出滚动、窄窗口、明暗主题下按钮不遮挡；原有文字选择和滚动正常。从正文开始拖选，在复制按钮上松开后，无按键移动不继续扩展选区、不误触复制。
- Tab/Shift-Tab 可进出、Enter/Space 和无障碍 Click 可用，点击按钮不折叠卡片；原有消息和代码块复制不回归。
