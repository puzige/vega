# Markdown 表格横向滚动

Issue [#796](https://github.com/puzige/vega/issues/796)。用户要求修复多列表格缺少横向滚动条、单次滚轮同时带动表格与会话的问题。

## 根因与范围

基线 `7c9bf1966043447716631ee5c13f8c3571bb5f32`。正文 `render_table_selectable` 和 `render_table` 仍使用原生 `overflow_x_scroll`，未配置真实横向 Scrollbar。固定 toolkit 的单轴默认滚动会把 Y 映射为 X，事件又继续传播到外层 List，与 [#584](../584/code-horizontal-scroll.md) 的代码块问题相同。以上来自静态源码核对，不是本地运行复现。

两条正文表格路径复用既有 `CodeViewport`：持久 ScrollHandle、横向 Scrollbar、稳定视口 hitbox、OngoingScroll 手势方向过滤及边界隔离。保留表格外层宽度约束与 flex-shrink 行为，沿用 `id_prefix + block_id + ordinal` 身份。Thinking 表格已经复用该组件，不修改。

不修改共享滚动算法、代码块、表格解析、列宽权重、最小宽、换行、选择复制、估高、主题、依赖或运行时数据；不新增产品说明文案。此规格补充 #59 与 #296 的局部横滚契约，不取代其内容和布局规则。

## 验收与回归

- 多列表格溢出时有真实横向滚动条，可拖动滑块及点击轨道查看最左和最右列；遵循系统自动隐藏/始终显示偏好。内容不溢出时不出现无效滑块。
- 普通 Y-only 滚轮/触控板输入只滚外层会话，表格 X 不变。
- X-only、横向主导的斜向手势只滚当前表格，外层 Y 不变；方向过滤、惯性与零 X 尾部、Ended/Cancelled 延续 #584 契约。结束后的新纵向手势仍正常工作。
- 横向到左右边界或没有溢出时不把残余 Y 交给外层；偏移保持在合法范围。拖动后视口边缘仍可接收滚轮。
- 两张表格、引用/列表中的多个表格保持独立身份；流式追加与历史渲染不重置现存表格偏移，不撑宽会话。
- 可选择及普通渲染两条路径保持列对齐、中文/inline code 换行、源文、链接和复制行为。拖动滚动条不开始或扩展文本选择；既有全局 mouse-down 可清除旧选区的规则不变。
- 窄/宽窗口、浅/深主题、流式/历史、Thinking 表格及长代码块作为手测回归；不声称本次改动给表格增加代码拖选自动横滚。

## 验证边界

本地只执行低 CPU 差异、格式及静态检查，不运行 Vega、构建或测试。此次只复用已存在的视口组件，不新增 Rust 开发测试或更改 CI。非实现者独立审查检查两条渲染接线、稳定身份、布局与选择边界；最终 head 通过完整 required Actions 后合并。CI 的 Rust 空集必须记为 0 发现/0 执行，不当作交互测试通过。物理触控板、滚轮、滚动条拖动和视觉效果待用户手测。
