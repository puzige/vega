# 新 turn 原生置顶

## 验收用例

| 前置 / 操作 | 可观察结果 | 验证 |
|---|---|---|
| 短文本或图片发送 | 新 turn 第一项首帧位于列表顶部；下方有回复生长空间 | 用户手测 |
| 回复、代码、图片、工具卡持续增长 | 不自动移动视口，留白随真实内容增长缩短 | 用户手测 |
| 滚轮、指针或键盘输入 | 立即暂停自动定位，不吞事件；上滚按实际位移回收留白 | 用户手测 |
| 主动滚回底部 / 点击回到底部 | 清除留白并恢复 Tail | 用户手测 |
| resize、历史分页、Fork、切换会话 | 临时留白清零；历史锚点与导航逻辑不变 | 用户手测 |
| reduced-motion、读屏 | 全程即时定位，无动画；留白只是 padding，无读屏节点 | 静态 + 用户手测 |

## 方案与变更记录

2026-11-01：沿用用户裁决，严格置顶优先。短 turn 所需留白可临时超过 `min(viewport × 2/3, viewport − 240)`，否则无法同时实现置顶；内容增长后回收。240px 是目标回复生长空间，小于 240px 的可用视口受实际窗口限制。24px 为用户累计离开位置的阈值，任何输入均立即取消待执行定位。

原生 GPUI 无 DOM、浏览器 scroll anchoring 或 CSS reduced-motion。本实现不引入动画，Normal 模式保留列表逻辑位置，不做逐帧滚动补偿。复用现有虚拟列表，留白作为底部 padding（叠加 composer 遮挡高度），不新增消息、焦点或 accessibility 节点。

新增布局包装元素，在 prepaint 获得真实视口尺寸后，按相同 row renderer 与真实宽度测量最新 turn，最多测量到一屏即停止。首帧先设置 Normal 与目标 ListOffset，再布局列表，避免 Tail 首帧上屏。后续布局根据内容高度计算所需 padding，只缩短而不主动改变位置。读取列表实际像素偏移计算用户位移，不用滚轮原始 delta，避免嵌套代码块横向滚动误回收。

输入捕获只更新滚动状态，不拦截事件。用户上滚按实际距离衰减留白；留白完全离开可用视口时清零。主动滚到底部恢复 Tail；显式回到底部也清零。新 turn 重新开始放置。历史分页、列表重置和 viewport resize 清除临时状态。权限卡不再强制打断新 turn 的放置，但非放置模式维持既有提示可见行为。

## 实现范围

仅 conversation_stream 的原生布局、发送落地和临时滚动状态。不改存储、历史分页协议、导航轨跳转、气泡配色或折叠。不新增依赖、动画、用户文案或 Rust 测试。

## 验证边界

本地仅格式、差异与静态 API 核对，禁止编译、运行和测试。编译与自动检查交现有 PR Check；真实首帧、混排、输入、resize、辅助功能与 reduced-motion 行为尚需用户手测。CI 的 no Rust tests 不代表行为测试通过。
