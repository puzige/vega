# 底部回到底部箭头闪现

## 授权与基线

用户确认只稳定显示、不改变现有滚动行为，并要求先建卡再实现。Issue #837 已建立并加入 Vega Desktop / In progress。基线 `cd742e96`，分支 `fix/bottom-arrow-flicker-837`，独立 worktree `vega-837-bottom-arrow`。

## 根因与实现边界

静态证据：`TurnList::paint` 捕获滚轮并调用 `interrupt`，后者无条件暂停 Tail；`render_resume_tail` 在列表本轮布局前读取 `following_tail`，于是把短暂停顿显示成按钮。列表布局随后会恢复底部 Tail。尚未进行运行复现。

只修改导航显示层：使用锁定 GPUI 已有的 `container_query`，保持导航区固定高度、全宽与不收缩占位，子内容在 prepaint 时构建。生产树先预绘制会话列表，再预绘制前景导航，因此读取的是当前列表已完成布局后的状态。保留原按钮全部视觉、焦点、键盘和点击接线，不加计时器、动画、帧间缓存或额外重绘循环。

显示条件：未跟随 Tail，且不在未中断的自动置顶，且没有已确认的实际底部几何。几何使用本轮列表视口、foreground 和现存置顶 spacer；从 logical top 起到末条必须连续测量，所有 bounds 有效且末端不超过有效阅读底边 + 1px。无有效视口、foreground 尚未知或条目未测量时不当作已到底。遍历在缺测或超出底边时立即停止，不测量/挂载历史，不扫描无关的上方历史。

不改 `interrupt`、列表滚轮处理、Tail 恢复/暂停、置顶、spacer 回收、分页、持久数据或依赖；#826 的自动置顶隐藏规则不变。不增加产品文案或控件。

## 验收与几何核对

- 到底后持续向下滚动不闪现；实际向上离开底部时正常显示。
- 回到底部/点击回底正常隐藏；鼠标、Tab/Enter/Space 操作接线不变。
- 流式新消息跟随、发送置顶及手动阅读历史行为不变。
- 长会话上方未测量不阻止确认已测量的连续尾段；中间缺测不得误判到底。
- 短内容、输入区增高、窗口缩放后使用本轮布局；几何未知不冒充到底。

验算：视口底边 600，foreground 180，spacer 0，有效底边 `600 - 180 - 0 = 420`；尾端 420 或 421 在既有 1px 容差内，尾端 422 不算到底。spacer 60 时有效底边 `600 - 180 - 60 = 360`；不忽略仍存在的置顶留白，也不改变该留白。
