# 凭据安全检查错误分类与诊断

Issue: https://github.com/puzige/vega/issues/862

## 目标与范围

运行时安全检查失败不能再等同于 API key 无效。凭据读取器将返回内容安全的结构化错误，贯穿主运行、子任务、最终 Provider 边界和摘要。区分凭据缺失/权限/格式/限制、数据库、配置协调、运行授权和工作线程失败；未知原因不得引导换 key。

不修改凭据匹配、隐私例外、授权验证、工具调度、自动重试或 continuation 的消费规则。所有错误仍 fail-closed；继续使用既有恢复收据和上下文恢复，不重放已完成工具。历史无分类记录显示中性的安全检查不可用，不追溯猜测根因。

## 最小实现

1. runtime 新增无文本载荷的凭据读取错误类型，保留阶段、分类和可取得的 SQLite/I/O 元数据；读取器不再返回 `()`。保留旧错误兼容历史。
2. app、MCP、隐私刷新、运行 fence 校验在来源处分类，消费者不再抹除原因。安全错误 Display/Debug 不包含配置、路径、凭据、底层任意消息。
3. 诊断 schema 仅增量添加凭据阶段和原因字段；已有 SQLite 和 I/O 字段沿用。严格白名单验证并同步诊断导出与重开会话映射。
4. 本地化提示区分凭据存储、内部存储/配置暂不可用、运行状态不可用；所有新分类仍走安全 continuation。只有凭据类故障显示凭据设置入口；旧未知错误不做凭据诊断。
5. 快速静态扫查其他模糊错误，单独记录，不自动实现范围外修改。

## 验收与风险验证

- 缺失、权限、格式错误仅凭据提示；数据库 busy/locked、配置协调失败不提示 key 无效。
- 错误在模型请求之前、之后以及准备摘要时均保留阶段/分类；SQLite/I/O 元数据存在时写入诊断，重开与即时提示一致。
- 所有失败仍停止安全边界；不吞错误、返回空凭据或添加隐式重试。
- 已完成工具回执和恢复操作身份不变；新错误与原安全错误一样创建 continuation 收据。
- 中英文键一致，最终无新增 Rust 测试。按项目规则本地只做格式/差异/静态检查；云端 required CI 和非实现者独立审查完成后合并；真实 UI 恢复由用户手测。

## 已有证据与限制

## 独立审查修正

- MCP 已完成调用后的结果净化失败保留类型化原因，与结果超限分开。内容安全的失败信息随终态回执传到运行层；先持久化完成事实、加入上下文/完成集合，再发出既有安全错误，建立 continuation。通用工具结果净化的同类失败也走此边界；不恢复未验证的原始结果，不自动重试远端操作。
- 启动期四个 readiness 入口保留 `CredentialRead` 分类并映射到准备失败诊断。准备诊断 JSON 增加白名单阶段/原因及已有 SQLite/I/O 元数据，启动期提示不再统一引导检查 key。取消仍独立处理。
- 通用 MCP 设置保留原 Conflict/Invalid/Store 映射；类型化安全读取独立处理配置协调及启动期清理，不把设置操作误称为可恢复的会话错误。
- 最终 required CI、无 Rust 测试清点与独立增量复核待完成；真实 UI 和不重放恢复仍需用户手测。

## 再次增量审查修正契约

- MCP 结果扣留及超限的固定终态文本必须被持久化和历史恢复的严格白名单接受；只增加精确匹配，不接受任意输出，不变更审批、操作身份和状态机校验。
- 通用净化失败沿用各工具现有校验认可的安全失败文本，额外携带类型化诊断；不得因新增说明文本破坏回执落盘。
- 未执行的历史读取拒绝保持 Rejected、原审批和未执行事实；净化失败只换用既有安全 fallback 并携带诊断，在有效拒绝回执落盘后安全暂停。不得把拒绝改成已执行的 Failed。
- 复用历史拒绝的安全替代投影只在原持久化状态同为 rejected、当前携带类型化安全错误且输出为固定安全 fallback 时进入专用校验；原回执与替代投影均须通过严格历史验证，审批、身份和元数据保持不变，原持久化记录不覆盖。
- 历史拒绝来源逐项覆盖 Validation、RunMode、Recovery、Cancelled：均仅接受各自原有文本/脱敏投影或固定安全 fallback，保留各来源的输入、审批和元数据约束；其他来源继续拒绝。
- 删除本卡新增的代码注释。首次同步 master `4b1eb052fec30a01d6420e8475042958a014535b` 仅含独立流式文字淡入，后续同步 `ce9c89e478715fa779ff290f058afe7cd0258cb7` 仅新增独立多击选择修复；修正后重新取得精确最终 head 的独立增量结论和完整 Actions。
