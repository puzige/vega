# 文件卡片外部间距

## 目标与范围

对应 [Issue #693](https://github.com/puzige/vega/issues/693)。正文末尾为行内代码或单独一行路径时，文件组与正文仍应有清楚的视觉层级。

- 正文与文件组外框之间保留 16 pt。
- 同组相邻可见文件行之间保留 8 pt 外部间距。
- 不增加卡片内部 padding、文件行高度、整条消息间距、文案或分隔线。
- 保留现有文件组标题、边框、预览/打开、更多文件、错误提示及组后复制按钮。
- 无文件组及空文件组不新增占位。

本规格仅替代既有文件组的外部间距规则，不更改附件数据、展示时机或交互契约。

## 根因与最小实现

`ArtifactGroup::render` 直接返回带边框的文件组，组前无专用留白；`render_compact` 文件行直接相邻。`copy_source_for_entry` 在存在文件组时将复制操作移至组后，所以不应通过修改正文或复制 footer 解决间距。

1. 在 `vega_theme::Layout` 增加 `ARTIFACT_BODY_GAP = 16` 和 `ARTIFACT_FILE_GAP = 8`。
2. 在 `artifact_card.rs` 的文件组外包裹层保留正文间距；从第二张可见文件卡片起添加上外边距，不改变卡片本体。
3. `ArtifactGroup::estimated_height` 同步计入组前及文件间距，空组仍为零；不改通用消息布局。

## 几何核算

设可见文件数为 F、现有行数（含更多按钮及错误）为 R。非空组预计高度为：

`16 + 44 + R × 36 + max(F − 1, 0) × 8 + 2 × 1`。

| 场景 | 预计高度 |
| --- | --- |
| 空组 | 0 |
| 1 文件，无错误/更多按钮 | 16 + 44 + 36 + 0 + 2 = 98 pt |
| 2 文件，无错误/更多按钮 | 16 + 44 + 72 + 8 + 2 = 142 pt |
| 3 文件，无错误/更多按钮 | 16 + 44 + 108 + 16 + 2 = 186 pt |
| 4 文件，折叠显示 3 个与更多按钮 | 16 + 44 + 144 + 16 + 2 = 222 pt |
| 4 文件，展开含折叠按钮 | 16 + 44 + 180 + 24 + 2 = 266 pt |

更多按钮和错误行不作为文件卡片，不额外施加文件间距。

## 验证与验收

这是局部几何调整，不新增临时 Rust 测试或源码字符串测试。本地仅差异、格式、静态检查；最终版本由现有 required Actions 执行编译、Clippy、Python 检查及 Rust 空集门禁（`no Rust tests` 不是测试通过）。合并前完成非实现者独立审查。

用户在更新后的应用手测以下场景，检查 16/8 pt 外部间距、浅深主题和窄窗口下的层级：

- 正文以行内代码路径结尾，后接单张文件卡片。
- 正文以换行路径结尾，后接多张文件卡片。
- 多于 3 个文件时展开/折叠，检查相邻文件间距与滚动定位。
- 无文件消息、空文件组、仅错误文件组不改变其他布局；错误与禁用原因仍可见。
- 预览、打开、更多文件及复制按钮仍可发现，原有键盘操作保持。

实际像素、交互及用户验收尚未执行；CI 与合并不代表用户手测通过。
