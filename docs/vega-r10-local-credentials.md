## Storage contract (implementation decision, approved by main)
- `<config.toml parent>/credentials/credentials.toml` is a TOML `keys` map. The configuration root is the trusted caller-selected anchor (canonicalized to support macOS `/tmp`); parent traversal components are rejected. No credential-derived path components. The owned `credentials` directory and all file operations use directory descriptors and `openat`/`renameat` with no-follow checks. Existing insecure permissions, wrong ownership, hard links, nonregular files and symlinks fail closed; never chmod unrelated existing files.
- Unix directory/file modes are exactly 0700/0600. Maximum file 1 MiB, 256 entries, reference 256 bytes, value 64 KiB. Errors are fixed, content-free variants; no secret-bearing Debug struct. Missing values require manual entry. Non-Unix platforms fail closed until equivalent owner-only support exists.
- A global process mutex serializes read-modify-write. Exclusive unique temporary files are synced before atomic rename, and cleanup runs on failure. No cross-process merge guarantee. The configuration root is trusted; malicious replacement of its ancestors by the same user is outside this boundary.
- Main approved direct `libc` (already transitive) on 2026-09-06 for minimal Unix descriptor-relative no-follow and ownership primitives.
