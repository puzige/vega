## 需求与优先级

用户观察到所有工具集中在第一块，最终回复后之前的说明仍占据正文。前者来自上一版固定头部承载全部工具的规则；本文件明确取代 `vega-issue-296-single-activity.md` §2 的固定头部收纳全部运行过程规则。保留单一运行状态/计时、右侧 hover/focus 箭头、轻量表面、原文、安全与真实阶段契约。

只读核查已确认：受影响的已完成 Native 轮次存在有效 Commentary/Final 元信息且正文范围可完整对应；后端没有丢失最终阶段。UI 在临时阅读保护触发时清除了待收起标记，离开回看后不再尝试收起。另一个仍 streaming 的轮次尚无 Final，应继续保留过程。公开记录不含原会话、工具参数或截图。

运行期间展示：本轮状态 → 说明 A → 对应思考/工具 → 说明 B → 对应思考/工具 → 最终答案。顶层状态仅表达本轮状态与时间，不能再复制所有工具到第一块。相邻且没有正文/事件边界隔开的工具可沿用现有工具组。工具详情默认折叠，每个操作仅呈现一次。终态后有可信 Final 时，过程说明与思考/工具统一进入一个可展开入口，最终答案留在外面。

不是删除历史：过程原文、原始工具输出、复制能力、顺序和身份都保留。未知/缺失/损坏 Final、失败、取消不能猜测最后一段就是答案；保留全部有效正文及时间线。ACP 没有可靠 Final 的现状继续保守降级。错误、授权、待回答卡片和产物保留独立外显。

## 最终阶段与自动收起

- 仅消费已有可信 `AssistantResponseMetadata`，Native 多次 response/tool 循环必须正确覆盖每段说明；重复元信息幂等，冲突/越界/UTF-8 非边界不得藏正文。
- 正文在 response 边界、工具边界与思考边界处必须保持正确的展示归属；不能因两个 response 合并到一个 copy 而永久遗漏应收起的过程。实时与存储恢复结果一致，原文不增删。
- 旧历史确有跨 response 的合并 copy 时，元信息验证通过后允许仅拆该 copy：首段保留原 entry key，附加片段用 response 起始字节的确定性后缀，其余 entry 不重编号。live 在同样的 response 边界采用同样后缀，原 ordinal 仍仅随原工具/思考边界推进；不能出现 live 过程 key 在重载后误命中 Final。重载必须稳定、原 key 仍可达；旧像素 offset 超出缩短后的首段时沿用有界定位，不承诺逐像素恢复。
- 首次可信 Final 确认后统一收起此前过程，不再受尾随、选字、焦点或此前展开状态阻挡；按 #416 处理隐藏选区/焦点，不主动开启底部跟随。
- 每轮仅自动收起一次；收起后的手动展开和主动搜索/定位仍有效，重复 Final、完成事件及重绘不能再次关闭。无 Final、失败/取消及无效元信息仍保留有效正文。
- 折叠后展开按源顺序显示说明与工具；最终答案不重复。锚点跳转/搜索/历史窗口恢复可到达原位置；未收起时在时间线就地定位，收起后在统一详情定位。
- 多轮用户请求互不影响；一轮折叠不能改变其他轮的正文、展开状态或锚点。
