## P1 实现路径

复用 inline_code::InlineFlow 的 FlowLayout/Fragment，而非移植 demo 的直接 ShapedLine paint。片段仍由既有 SelectableStyledText/InlineCodeText 生成 TextLayout，供选择、图标、虚线、命中与预览登记共同使用。
新策略明确限定在 assistant SelectionDocumentBuilder，默认路径不变。flow 中加入可选中文禁则边界：使用 shaped glyph 边界，保持正向推进；最小不可分标点组可溢出；重试只接受严格缩短的边界。
assistant 行内代码采用 .92 倍继承字号、6px 水平 padding、1px 垂直 padding 和 6px 圆角；默认共享策略保留旧值。P1 不提前替换各块的正文字号/行距，F=16/1.625 的全块视觉切换留 P2。

排版先按实际片段字号/图标/padding 计算可容纳字形范围，再以整行上下文恢复词边界并应用禁则；不可分最小组允许溢出，所有重试必须严格缩短。片段保留字号、行高和基线偏移；使用同样的 style refinement 创建并绘制片段 TextLayout，选择与链接继续消费该 TextLayout。行高至少容纳实际 ascent/descent 和背景，所有片段共享基线。背景只绘制，不注入复制字节。行盒按 Window::pixel_snap 与 TextLayout 同规则取整后计算基线。代码标签链接以片段元数据携带前置 padding，图标绘制、命中与预览登记统一读取该偏移，保持图标与代码底之间 4px 间隔；默认链接偏移为零。

代码块及非 assistant 入口不启用新行内策略。静态审查、云端与用户验证分别记录；源码完成不代表 P1 验收完成。

## P3/P4 接线核对与度量失效

静态核对：`content.rs::apply_event` 的 TextDelta 只 append 活动消息并置 dirty；`render.rs` 仅同步该尾项。MessageFinished、Interrupted、Error 均进入 `finish_agent_message`，调用 `finish_model` 后使尾项高度失效；历史 hydration 同样调用 `finish_model`。`MarkdownStream::absorb` 只对新增/invalidated 块解析，后置引用更新递增指定块 version；`StreamModel::sync` 按 identity/version/pending key 复用。已有 generated-notice 投影在投影文本变化时重建本消息，此例外不扩展至全历史，也不误称普通增量每帧均零重建。

`TextCache` 仍按 incarnation/revision/逻辑宽度缓存估算，保留 2048 条/2MiB/单条 4KiB 上限与阅读区/尾部配额；估算不是原生字体测量。可见消息高度由 list bounds 回填，并只保留阅读区附近。宽度变化、单项内容变化及分页分别沿用现有重测/identity 锚点恢复，不主动重新开启已暂停的尾部跟随。`InlineFlow` 每次 request_layout 读取当前样式/宽度，prepaint 按实际 bounds/scale 复用或重算；内容变化继续使选区失效。

新增最小适配：`core.rs` 保存可选布局环境，`text_cache.rs` 比较继承 Font（family/features/fallbacks/weight/style）、rem 像素与窗口 scale，`render.rs` 在渲染入口刷新。只在已登记环境发生变化时清除估算/实测高度并以 `list.remeasure_items(0..list.item_count())` 绝对偏移模式重测，按原 identity、item offset 和 following-tail 状态恢复锚点；首次登记及普通流式帧不触发全量重测。不改 Markdown 内容缓存，不引入运行时字体设置或全历史重解析。此路径覆盖原 List 仅按宽度自动失效而未检查字体/scale 的缺口。

以上是源码接线证据，不证明 stop/error、引用更新、跨屏缩放、选择交互、锚点或性能实测通过。P5/P6 验证与用户验收仍待完成，未合并、未发版。
