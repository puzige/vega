# #696 上下文窗口 hover 浮层

## 来源与范围

用户要求对齐其提供的 Codex 可见截图，内容仅在 hover 态展示，UI 尽量 1:1。仅依据可见截图，不使用第三方内部资产，不公开原始会话截图。

基线：`672d2bef`。仅调整 Native composer 圆环与浮层、展示格式、共享主题 token 和本地化；不改真实 usage 来源、分子分母、压缩、请求估算、计费、权限及 ACP。

本规格替代 #490、#575、#682 中点击固定、focus 打开、详情卡布局及相关可见文案；#682 的真实 usage 和无历史时隐藏契约继续有效。通用设计守则的 focus 等价可见入口在此只读指示器上由用户明确的 hover-only 要求替代，保留键盘 focus 和完整可访问名称读取实际信息。

## 行为

- 仅在有会话内容且真实 `last_call_total` 为 `Some` 时显示圆环；`Some(0)` 是有效数据，仍显示。无真实 usage 时隐藏圆环与浮层，不保留占位或键盘焦点入口；仅有容量配置或预测用量不视为真实 usage。默认不显示常驻 token 文案或面板。
- 只有指针悬停圆环命中区时显示浮层，离开即消失。点击、Enter、Space 和单纯 focus 均不固定或打开浮层，不抢 composer 焦点、不关闭其他菜单。
- Esc 可关闭本次 hover，离开再进入恢复；菜单切换、设置打开、线程切换按已有重置入口清除 hover。
- 保留圆环可访问名称与键盘焦点，读屏可读实际用量；focus 不触发视觉浮层。

## 视觉与文案

- 浮层锚定圆环中心上方，不再锚定整个模型控件右侧；窗口边缘自动避让，deferred priority 2 保证不被 composer 边框盖住。
- 深色背景 `#1B1E1F`，主文字 `#FFFFFF`，次文字 `#A1A1A1`，边框 `#303334`；浅深主题都保持参考图的深色提示样式。颜色全部进入 ThemeColors。
- 最新参考图优先于中途两行方案：保持标题、百分比、token 用量三行，所有行禁止折行。178 为最小宽度，实际宽度按当前字体测量三行的最大文字宽度，加水平内距与边框后向上取整；不截断、不依赖固定宽度猜测。采用 16 圆角、水平内距 16、垂直内距 4、1px 边框、行高 20、13px 正常字重，三行居中，轻阴影，无箭头。高度验算：3×20+2×4+2×1=70；宽度至少为最大文本宽+2×16+2×1。锚点随实际宽度保持圆环中心对齐，与触发器顶部间隔 6。
- 正常已知用量严格三行：`Context window:` / `9% used (91% left)` / `43k / 475k tokens used`；中文使用对应本地化。标题次色，后两行白色。不再使用 `full`；剩余百分比为 100 减已用整数百分比，超额时最低为 0，不显示负剩余。
- 百分比用真实分子/分母四舍五入到整数，允许真实超过 100%；不钳制显示值。圆环仍按原有规则钳制至满环。
- 紧凑 token 沿用现有 k 格式（保留必要一位小数），不改真实计数。
- 有 usage 无容量：第二行为“容量未设置”，第三行仅实际 used tokens；无 usage 时不渲染圆环或浮层，不用空环、零值或“暂无数据”占位。
- 移除可见帮助/关闭按钮、条形进度、预测请求、来源说明；这些不是当前查看用量所需内容。保留完整既有读屏信息。

## 验证与风险

用户手测：浅/深主题、默认/hover/离开、点击/Enter/Space/focus 不固定、Esc 后重新 hover、已知/未知/0/超额 usage、模型/线程切换、窗口边缘、菜单共存及浮层不被 composer 边框穿过。截图像素对齐尚待用户真实手测，不以静态检查或 CI 冒充视觉验收。
