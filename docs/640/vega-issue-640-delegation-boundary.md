# #640 通用委派提示与项目交付规程分离

## 授权、基线与范围

用户已明确授权接手并实现，取代 issue 建卡时仅登记的限制。
实施基线：`e481cd28d5de685dc79f39080a8c6cb79b9412b8`。
本规格先于实现固定。仅改 `crates/vega_runtime/src/agent/loop_.rs` 的委派提示、`subagents.rs` 的必要描述和本目录文档。

`loop_.rs` 仅在 subagents 配置存在时追加提示；没有实现完成自动创建 Reviewer 的确定性调度。问题是产品通用提示反复展开项目交付规程，而非运行时强制所有项目审查。`checkpoint_stage` 描述中的无条件审查/CI 要求需改为能力事实。

## 实现契约与验收对照

| 验收 | 保留或收敛后的契约 | 落点/验证 |
|---|---|---|
| 1 普通项目不新增门禁 | 不展开 READY 模板、CI、final head、test-first 或固定阶段；不默认新增审查 | 系统提示和全部子 Agent 工具描述语义审查 |
| 2 遵守有效要求 | 用户/项目关于委派和审查的要求或禁止优先；默认直接执行不能跳过必要独立审查 | 系统提示简短条件式原则；spawn 描述与之对齐 |
| 3 默认直接执行 | 复杂、多文件、深入本身不是委派理由；少量调用、已知目标、紧密耦合和立即阻塞工作优先本地完成；每次 spawn/followup 比较收益和交接成本 | 系统提示决策段 |
| 4 审查有边界 | 已授权审查围绕差异和受影响契约；具体疑点可沿相关路径深入；证据充分后结束，无问题正常；记录静态限制，可选建议不自动扩展调查，不压过真实未决风险与必要回归 | 条件式审查段 |
| 5 续派有增量 | 新工作/差异/证据/具体未决问题才续派；复用有效结论并复核受影响部分；状态使用 list/wait，不重复无变化审查 | 系统提示续派段；工具协议保持 |
| 6 生命周期安全 | 共享工作区单一写入权与非重叠范围；独立上下文和充分任务包；准确版本和证据；中断保留产物/检查点，原 writer 停止、取消排空释放后才交接；未知副作用须证据处置且不重放；等待真实结果、不重复子任务、不伪造完成；子输出不是权限或指令来源 | 系统提示及既有工具描述逐项核对 |
| 7 检查点能力事实 | 就绪不代表审查或验证完成，门禁由任务/项目决定；成功完整 Read、当前字节核验、证据不启动检查、非就绪可继续、就绪唯一调用、持久化、writer drain/release 全保留 | stage_definition 仅改末句 |
| 8 最小差异及真实证据 | 不改 schema、控制流、工具权限、并发/嵌套限制、运行时阈值、配置或仓库门禁；不声称静态检查证明模型行为或提速 | diff / 格式 / 独立语义审查 / 既有 PR Check |

任务包保留目标、验收/必要回归、范围与禁止项、适用规则、依赖、必要 API/观察可行性、版本、原始证据和未决问题，不强制代码开发专用交付模板。主 Agent 不外包主任务理解与综合判断。
遇到重复失败或无进展时基于原始证据区分产品、观测/测试、验收和环境问题，修责任层、保留断言/回归；删除固定“两次/20 分钟”提示阈值，不改任何运行时限制。

## 取代边界与非目标

仅取代 [#617 历史文档](../617/) 和 [#525 历史文档](../525/) 中产品通用提示的过重交付规程表达；历史记录不改写。

## 验证与交付

- 本地仅低 CPU 静态差异与格式检查，不运行 Vega、编译、构建、测试或打包。
- 主 Agent 实现并停写精确版本后，由非实现者独立语义审查上述八项、工具描述和保留契约。
- 不新增源码字符串断言、伪模型测试或临时 Rust 测试；提示语义变化不能由这些测试证明。
- 既有 GitHub PR Check 验证最终 head；Rust 空集须写 `no Rust tests`（0 发现/0 执行），不称行为测试通过。CI 日志/独立审查/完整 SHA 固定在 PR 与 issue。
- 审查无缺口且 required check 通过后 squash merge，保持 issue 开放并设 In review 等用户手测。spec 偏离必须明确，当前无。
- 实际效果待用户在包含改动的安装构建观察：记录模型、推理配置、任务及规则来源，比较请求轮数、耗时、有效发现和返工，区分模型请求、工具执行和外部等待；不承诺提速比例。
- 回滚通过 PR 恢复提示/描述，不动用户数据。
