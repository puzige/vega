# Issue #147：会话 Markdown 局部选字与复制

## Freeze

- 关联：[Issue #147](https://github.com/puzige/vega/issues/147)
- 范围：会话中用户正文气泡和助手 Markdown 回答。文件预览等复用 Markdown 组件的非会话视图先不包含。
- 一个消息气泡是一个选择区域；不跨消息、工具卡、权限卡、思考区或元数据选择。
- 不依赖外部程序或新增依赖；沿用 Vega 的 GPUI 与主题 token。

## 用户可见行为

- 在会话正文按下并拖动鼠标可选中局部文字，并显示浅色、深色主题均可辨认的选区。
- 选择范围可跨同一条消息内的段落、标题、代码、列表、引用和表格；屏幕软换行不变成复制换行。
- 右键打开该选择区域的上下文菜单。选区非空时“复制”可用；无选区时“复制”禁用。点击复制只写入选中的可见文本，不包含相邻消息、头像、状态、工具元数据或 Markdown 语法。
- macOS Cmd+C 复制当前非空会话正文选区。Composer 有焦点时沿用 Composer 的键盘与剪贴板行为；无正文选区时不截获 Cmd+C。
- 右键菜单不清除选区。拖动选择不会触发链接、折叠控件、发送或其它行操作；本次不新增链接导航行为。
- 流式正文有变化时，清除该消息的旧选择；切换任务、替换历史内容或复用行视图时，旧选择不能指向另一个消息。
- 手动滚动会话正文后，选区仍映射到原消息文字；裁剪/回收行不崩溃，也不改变复制内容。

## 复制文本规则

- 按当前消息中实际显示的文本顺序复制；加粗、斜体、删除线、行内代码与链接只复制可见文字，不复制 Markdown 标记或链接地址。
- 同一段落的 Markdown 软换行复制为一个 ASCII 空格，不插入软换行；两个相邻块之间使用一个空行（`\n\n`）。
- 列表项之间使用 `\n`，并复制可见的项目符号/序号、缩进及任务复选框标记。
- 代码块保留原有字符、缩进和行内 `\n`；不复制代码围栏。
- 表格单元格之间使用制表符，行之间使用 `\n`；不复制表格分隔线。
- 引用块只复制可见引用文字；水平分隔线没有复制文本。选择范围两端按 UTF-8 字符边界夹取，不截断中文、组合字符或 emoji。
