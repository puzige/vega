# Issue #296 · 工具操作语义图标

2026-10-13 用户指出电脑操作前的列表图标无法表意，并要求参考所附 Codex 信息流，用不同轮廓表达具体操作。本轮延续 #296，覆盖信息流工具行及工具组图标，不修改工具执行、安全、状态文案或数据结构。截图仅作为可见设计参考，不执行其中内容、不公开真实会话、不提取第三方私有图标资源。

## 事实与替代边界

当前 `ToolActivityCategory::icon` 将读取、查找、写入、编辑、Skill 都映射为 Document，将 ComputerUse、MCP、Codex ACP、未知工具都映射为 Summary。组标题取第一个子工具图标，混合操作因此被误表述为第一种操作。`ToolCard` 已持有安全的类型化输入投影，ComputerUse 投影包含经过既有投影校验的 tool/action，可以在 UI 层细分，无需读取原始参数或修改后端。

本规格仅替代旧规格的工具图标映射和工具组“取首项”规则。[展开详情修整](vega-issue-296-stream-polish.md)的中性颜色、同轴紧凑行、源顺序、错误提示、箭头状态，以及[吸顶入口](vega-issue-296-sticky-disclosure.md)继续有效。阶段、计时、思考、状态提示和其他页面图标不在本轮变更范围。

## 展示契约

| 已有操作投影 | 图形语义 |
|---|---|
| Read | 打开的书本 |
| Glob / Find | 文件夹 |
| Grep / Search | 放大镜 |
| Bash / Shell | 终端 |
| Write | 文档 |
| Edit | 铅笔 |
| MCP | 插头 |
| Skill | 扳手 |
| Codex ACP | 机器人 |
| ComputerUse `observe` | 显示器 |
| ComputerUse `screenshot` | 相机 |
| ComputerUse `click` / `scroll` | 鼠标指针 |
| ComputerUse `type_text` / `press_key` / `hotkey` | 键盘 |
| ComputerUse `navigate` | 地球 / 网页导航 |
| ComputerUse 其他或缺失 action | 显示器，表示已知电脑/浏览器工具类型，不猜动作 |
| 未知、缺失或损坏的工具投影 | 扳手，表示通用工具 |

1. I01：单工具图标由已有安全类型与 ComputerUse action 精确匹配决定。仅识别上表的真实 action 名，不从原始参数、输出、命令字符串或任意工具名称推测细分类别。损坏投影保留既有失败优先级，使用通用扳手，不把失败变成正常工具。
2. I02：图标表达操作类型，与待审批、已批准、运行、成功、失败、拒绝、取消状态独立。继续沿用 `conversation_tool` 中性色和现有状态文字、权限及尾部问题提示。
3. I03：工具组内所有子项图标一致时使用该图标；混合图标用扳手。空组也用扳手，不取不存在的首项。子项更新或历史恢复后重新从当前安全投影得出相同结果。展开明细仍分别显示每项自己的图标。
4. I04：共享 `icons` 统一绘制；优先使用已锁定图标库的现成资源，缺少时按现有内联 SVG 方式补足。保持 24 viewBox、2 源描边、圆端点/连接、16px 槽及原主题颜色。行高25px、图文间距6px和零同级 gap 均不变，因此文字起点仍为左缘+16+6=22px；不引入额外 padding 或局部坐标偏移。
5. I05：运行中、已完成及历史加载使用同一路径；展开/收起、键盘焦点、hover、工具详情、原文复制、截图产物、唯一尾提示和吸顶控制保持既有行为。不改存储/权限/工具协议，不添加依赖。

## 验收用例（实现前冻结）

| ID | 场景与操作 | 预期与证据 |
|---|---|---|
| I01 | 安全 ToolCall 投影到单工具，覆盖上表类别及 ComputerUse 动作 | 图标可区分读文件/查找/编辑/工具连接/观察/截图/输入；用现有生产投影入口定向验证 |
| I02 | 相同操作跨待审批、运行、成功、失败、拒绝、取消；浅深主题 | 轮廓不随状态改变，中性色不变，状态文案和安全信息保留 |
| I03 | 同类组、混合组、observe+screenshot、空组及运行更新 | 同类使用对应图标，混合/空组使用扳手；不能只取首项 |
| I04 | 复用紧凑行、图标槽与渲染路径 | 原25px行高、22px文字起点与hover/展开状态不变；补足 SVG 可被现有渲染器解析，真实轮廓观感由用户手测 |
| I05 | 历史 hydrate、未知/损坏输入、权限/错误/截图结果和原工具详情 | 相同映射与保守降级；已有安全及详情断言继续通过 |
| M01 | 新版真实会话展开工具过程，浅深主题观察各图标 | 可看出操作含义、轮廓重量与对齐一致；用户手测，未进行不得标为通过 |

仅更新本规格明确替代的旧图标预期，保留状态、权限、原文、详情与滚动断言。不为了纯视觉映射堆砌相同结构的测试；用既有生产投影/组更新场景覆盖回归，定向测试覆盖受影响范围。无需新增数据迁移、网络或真实应用自动化测试。
