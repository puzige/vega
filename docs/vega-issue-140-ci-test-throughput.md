## Experiment decision rule

2026-09-22 follow-up: the four named package debug-information experiment changed only23 of801 Cargo units, but the measured runtime-package build increased15.61s to26.37s with only1.2% binary reduction. Reject the candidate; no Cargo profile override is delivered. Existing cloud failures in another PR exposed an output-overflow fixture timing out before emitting bytes and a generic PTY wait timeout; T10 permits bounded fixture/race investigation within CI reliability scope, without claiming the logs prove an exact PTY phase.

Archive reuse is a hypothesis, not predetermined acceptance. If transfer/serialization makes it slower after reasonable small tuning, preserve evidence and deliver the faster native topology instead. Likewise, more shards must win actual completion time to become default. Each of four directions must have a concrete implementation or measured rejection, not an unsupported promise. No claim of guaranteed zero flaky tests.
