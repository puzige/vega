# 对话运行时隐藏复制入口与菜单

版本：v1，2026-10-26。Issue：[#630](https://github.com/puzige/vega/issues/630)。基线：`410758d36e8fbe0802f816227948ece1486d8494`。

## 目标与边界

当前会话由 worker 持有期间，隐藏该会话全部用户消息、助手正文、代码块的复制按钮，以及消息/思考正文的右键复制菜单。包括历史消息，不仅限于当前流式段。未运行的其他会话不受影响。保留选字、Cmd+C、链接、工具、权限、提问、停止与 Composer 操作；不隐藏应用或工具本身的其他菜单，不增加提示文案。

运行边界使用现有 `actions.running`：从 `begin_composer_run` 的准备阶段到 `finish_composer_run` 的 worker 终态释放，包含思考、工具、权限/问题等待、停止后的排空和提前收到 Final 元数据。不以是否正在输出 token 或 Final 元数据作为结束依据。独立的消息活动状态 `active_agent_message` 也应隐藏入口，避免历史恢复/独立事件路径遗漏。

## 先行验收

| 前置/操作 | 可观察结果 | 验证 |
|---|---|---|
| 空闲会话，hover/focus 用户消息或符合现有资格的最终回复 | 复制入口及右键菜单沿用原行为 | 静态链路、用户手测 |
| Native/Codex 启动运行，hover/focus 当前及历史消息 | 无消息复制按钮、无代码复制按钮、右键不打开复制菜单 | 静态链路、用户手测 |
| 思考/工具执行、权限/问题等待、Final 已到但 worker 未释放、停止排空 | 仍隐藏入口，不提前恢复 | 生命周期静态核对、用户手测 |
| 运行前已打开右键菜单，随后启动运行 | 菜单清除；运行结束不会重新出现旧菜单 | 菜单状态静态核对、用户手测 |
| 成功/失败/取消后 worker 释放 | 依原有可信 Final/Codex/失败资格恢复入口，不扩大复制来源 | 静态核对、用户手测 |
| 运行期间选字及 Cmd+C；链接、工具、权限、停止 | 原有行为保留 | 静态核对、用户手测 |
| 浅深色、长代码、滚动到历史消息、切换空闲会话 | 无透明可点击/可聚焦复制按钮；布局不因隐藏控件跳动；无跨会话影响 | 用户手测 |

## 根因与最小实现

`render_rows::message_with_copy`、`code_header` 与 `SelectionMenu` 没有会话运行条件，用户消息无条件添加复制控件；助手可信 Final 可早于 worker 释放。`ThinkingBlock` 独立渲染也挂载复制菜单。

1. 在会话渲染层计算统一复制入口资格，并通过轻量交互上下文传到消息/代码渲染与过程详情。只条件挂载实际按钮，保留既有 footer/header 几何，保持复制来源和高度估算不变。
2. `SelectionMenu` 接收 enabled；禁用时清除已开菜单及订阅，不注册右键监听，阻止延迟打开回调恢复旧菜单。
3. 思考正文通过现有 retained thinking 集合在 worker 开始/结束更新菜单资格，新建思考块继承当前资格；历史思考卡在被渲染时同样核对会话资格。
4. 不改存储、runtime、依赖、复制文本、自动发布或通用 CI，不新增 Rust 测试及专用支持。

## 验证与交付

这是局部 UI 可见性变化，使用静态调用链/状态检查、格式/差异检查、非实现者独立审查及既有完整 PR Actions；不为流程临时造 Rust 测试。本地不运行 Vega、不编译/构建/打包/测试。云端保留 fmt、Clippy、三组 Python 检查与 Nextest 清点/执行；空集记录为 `no Rust tests`，不称行为测试通过。

最新 head required check 通过且独立审查无缺口后 squash merge，Issue 保持开放并置 In review 等用户手测。没有应用安装或真实剪贴板/键盘/像素验收证据时明确未验证。回滚本卡统一交互资格及菜单变更，不改用户数据。
