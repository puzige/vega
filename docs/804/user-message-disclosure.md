# #804 用户消息减灰与长消息折叠

## 范围与基线

基线 `6adf863bdb568d14c69635690591dcaef7b21403`。仅修改已发送用户消息的展示；继承 [#800](../800/user-message-markdown.md) 的完整源文、模型输入、存储、整条复制、附件在上/正文在下、纯图片无空气泡及 Markdown 横向滚动契约。用户正文颜色、字号与 70% 最大宽度不变。Issue 中给出的数值作为本卡验收要求，不引入第三方资源或继续解包研究。

## 视觉契约

- 气泡底色使用当前主题 accent 的 10% 透明叠加，浅深主题均适用。
- 用户气泡圆角 22px，左右内距 16px，上下 10px。
- 普通正文行高为当前字号 + 4px；相邻普通段落额外间距为零。标题、列表、引用、代码和表格保留层级间距及自身排版。
- 用户行内代码使用透明叠加：浅色黑 5%，深色白 10%。助手正文及行内代码 token 不变。

## 折叠契约

- 完成态用户 Markdown 按当前气泡可用宽度测量；超过 20 个正文行高的展示高度，或源文超过 10240 Unicode 字符时，可折叠并默认收起。恰好阈值不折叠。长单段自动换行与中英文均包括在内。
- 收起预览以 19 个正文行高为目标，末尾另显一行 `…`。标题/列表/引用/表格等结构计入实际高度；必要时少于 19 行，不能以像素遮罩保留隐藏控件。截断处的代码块完整显示，不切断；超长首个代码块可使预览高于目标，仍保留展开动作及尾部隐藏规则。
- 表格按当前列宽逐行测量，收起投影仅保留剩余高度可容纳的表头和完整数据行；不切断单元格。表头自身无法容纳时隐藏该表格，仅保留展开入口，不将整张首块表格作为超高例外。投影沿用原列宽权重，隐藏行不参与渲染、选区或链接操作；展开及整条复制仍保留完整表格。
- 预览从已有 Markdown 模型派生，不重新解析或改写原文；隐藏的行、链接和复制按钮不加入元素树/选区文档，因此不可聚焦、激活或被辅助功能读取。跨越截断边界的链接不保留部分可点击链接。
- 气泡内右下方只显示 `Show more` / `Show less`，中文为“展开更多”/“收起”。按钮有可访问名称、Button role、真实 expanded 状态、Tab 焦点及 Enter/Space 操作；可在模型运行时展开阅读，不受消息编辑/复制禁用状态影响。
- 展开状态为本消息 UI 生命周期内状态，不写存储，不影响后续消息。重渲染保留；宽度变化重新计算预览。切换前清除旧选区，避免复制已经隐藏的内容。
- 省略号和按钮不进入选区文档；选区复制仅可见正文，整条复制仍走原 MessageCopy 完整源文。附件、时间戳、消息页脚和滚动跟随策略不变。高度估算使用相同可见投影与用户排版。

## 实现与验证

主 Agent 最小实现，无新依赖、数据 schema、模型协议或 Rust 测试。本地仅快速 diff/rustfmt 静态检查，不运行/编译/构建/测试 Vega。完成后由非实现者独审精确版本，最终完整 required CI（含 Rust 0 发现/0 执行）通过才合并；原生像素、键盘、剪贴板、窄窗和滚动由用户手测，CI 不冒充手测。

手测矩阵：短消息；恰好/超过 20 行和 10240 字符；中英文长单段；截断边界链接/代码/列表/引用/表格；首块超长代码；运行中阅读；多个消息独立切换；历史恢复与宽度变化；浅深主题；完整源文复制/选区/代码复制；附件顺序和纯图片。用户通过前 Issue 保持开放，合并后 In review。回滚整体撤销本卡差异。
