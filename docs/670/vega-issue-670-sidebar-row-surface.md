# #670 — 最近任务与项目文件夹的背景留白

## 授权与规格关系

用户已确认以置顶任务为基准：最近任务与项目文件夹的交互背景向左外扩 8px，同时保持文字、图标、右侧按钮位置不变。先补充规格，再修改实现。

本规格扩展 [R36](../vega-r36-sidebar-row-surface-inset.md) 的适用范围，取代其中“最近任务与项目行不变”的排除项；置顶任务本身不变。保留 [设计守则](../vega-design-guidelines.md) 的语义色、32px 行高、8px 圆角与层级缩进。

## 问题与范围

- `ThreadsBlock::render_recent_row` 当前传入前导外扩 0、内容内距 0，因此文字紧贴背景左缘。
- `render_pi_project` 当前仅设置右内距，因此文件夹图标紧贴背景左缘。
- 置顶任务使用左外扩 8px、内容内距 8px，并在其列表容器中保留外扩空间，是本次对齐基准。
- 仅修改当前 organization 侧栏中的最近任务与项目文件夹；不修改旧投影、项目子任务或置顶任务几何。

## 实现契约

设原始内容左缘为 B、行右缘为 R：

| 对象 | 修改后背景左缘 | 内容位置 | 右缘 |
|---|---|---|---|
| 最近任务 | B − 8px | 标题仍在 B；右侧操作与状态槽不移动 | R 不变 |
| 项目文件夹 | B − 8px | 图标仍在 B；名称仍在 B + 16px + 8px | R 不变 |

1. 最近任务行外扩 8px，内容补回 8px，沿用置顶行已有几何参数；重命名分支单独补回 8px，保持编辑器原有位置与宽度，不改变其他行的编辑器。
2. 最近任务列表容器采用与置顶列表相同的 `ml(-8px) + pl(8px)`，保留列表内容列与右缘，同时让外扩背景位于滚动裁切范围内。
3. 项目文件夹行采用 `ml(-8px) + pl(8px)`；项目列表容器采用同样的抵消组合，保留文件夹、子任务、渐进展开控件及右侧按钮坐标。不得在整个项目分组上新增会移动子任务内容的内距。
4. 背景边界在默认、hover、选中、focus-visible、菜单打开、运行与拖拽状态保持一致；沿用现有颜色、状态判定、动作可见性、焦点和事件处理。
5. 使用既有 8px 间距原语；不新增颜色、字号、全局 token 或产品文案。

几何核对：列表容器左移 8px 再补回 8px，内容列仍是 B；行左移 8px 后补回 8px，内容仍是 B，新增宽度被新增左内距消耗，因此内容可用宽度及右侧槽位不变。项目子任务不外扩，仍保持原坐标。

## 验收与回归

- 最近任务与置顶任务的背景左缘一致，标题坐标和截断宽度不变。
- 项目文件夹背景在图标左侧保留 8px；图标、名称、子任务、Show more 与右侧按钮坐标不变。
- 默认、hover、选中、键盘焦点、菜单打开、运行状态下不跳动；保留选中判定及焦点可见性。
- 最近任务进入重命名及确认、Esc/外部点击取消时，编辑器位置和已有行为不回退；其他行重命名不变。
- 浅色/深色、240px 窄侧栏、长名称和列表滚动时，背景不被左侧裁切，右侧按钮可达。
- 项目展开/折叠、归档筛选、拖拽排序与渐进加载保持原有行为，拖拽行边界跟随新的完整背景。

## 验证边界

本地仅做差异、格式、文档链接与调用链静态检查，不运行 Vega、不编译、不执行测试。此次为有限几何修复，不新增临时 Rust 测试、测试接线或依赖。编译及 required CI 尚需 GitHub Actions；真实像素、键盘焦点和交互由用户手测，静态推导不能代替运行验收。

## 非目标

不更改排序、折叠、导航、选中逻辑、存储、行高、圆角、配色、右侧操作槽位、项目子任务缩进或置顶区现有布局；不引入额外说明文案。
