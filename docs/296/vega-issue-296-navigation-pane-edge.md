# #296 消息导航与侧栏边界

2026-10-13 用户追加反馈：消息导航刻度应贴会话面板左侧，不随居中正文移动；侧栏与会话之间不应出现额外细白带。参考图只作本地视觉证据，不公开原图及会话内容。

## 契约

- N01：rail 相对真实会话消息视口左缘固定定位，沿用 `MESSAGE_ANCHOR_LEFT_INSET=4` 与 `CONVERSATION_NAVIGATION_GUTTER=24`。中心为视口左缘 + 4 + 24/2 = 16；与正文最大宽、居中留白无关。侧栏折叠、拖拽及右侧 Workspace 改变 pane 时仍成立。
- N02：保留 6×2 普通刻度、10 节距、真实消息身份和数量、当前项、滚轮窗口、键盘/点击跳转及 hover 预览；预览在 rail 右侧并保持 pane 内可达。短内容不显示导航，正文与 Composer 宽度和同轴不变。
- N03：侧栏 resize 命中宽保持现有 5，不能用缩小命中框消除白带。拖拽区延续侧栏表面，仅在与会话接界处绘制现有 1px 主题分隔线，不保留中间白色轨道或双线。算术：5px 命中宽内，4px 侧栏背景 + 1px 分隔线；不增加布局宽度。浅/深主题均适用。已核对根因：透明拖拽区露出主背景，原中央1px线两侧各露2px主背景。
- N04：不改持久化、导航状态、消息/图片内容或权限，不安装或操作正在运行的应用。
