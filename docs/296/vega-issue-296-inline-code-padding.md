# Issue #296 · 行内代码左右留白

2026-10-13 用户反馈：行内代码文字贴着灰底边缘，要求参考所附 Codex 截图增加左右留白。只据截图可见形态调整 Vega；不发布截图或其中会话。

## 契约与范围

- P01：非空行内 code 两端各预留 4 逻辑 px，灰底包含该留白；文字与相邻正文的布局必须同时让位，不允许单纯扩背景覆盖邻字。共享 Layout token；延续原字体、基线、底高、圆角、主题色及行高。
- P02：两条 Markdown renderer 共用实现，覆盖正文、列表、表格及复用 Markdown 的预览。code 仍参与自然换行，不变成不可断行的独立控件；保留显式换行、原顺序及空 code 无多余留白。每个视觉行内 code 片段左右各4px，空片段不产生独立的 padding-only 行。
- P03：原始文本及复制内容逐字不变，装饰不得进入源内容或剪贴板。命中、拖选、部分复制、链接位置及选择绘制顺序须与实际显示几何一致；布局宽度改变仍更新测量和锚点。
- P04：不改 fenced code、parser、表格分列策略、协议、持久化或全局字体。不加依赖、不扩公开 API，不新增代码注释。失败路径保持原有行为。

本页替代 inline-code-layout C02 对“背景严格等于文字宽度”的限制，其余契约保留。P01 数值核算：原字形宽 W，非换行片段两端装饰为 4+4=8，因此占用 W+8；相邻正文须在该完整占用之外。原字体13.5、行高23时灰底仍为17.5高，上下各2.75，不用新增高度换取横向留白。
