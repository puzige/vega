# Issue #146 — 完成本轮耗时与中间过程折叠

规格冻结：2026-09-25

## 目标

运行期间让用户看到本轮 thinking 与工具进度；运行结束后将中间过程收为可再次展开的入口，并显示本轮总耗时。最终回复始终直接可见。长过程复用 #103 的有界滚动能力。

## 口径

- 一轮从应用接受用户提交并开始 agent runtime 时计时；前置模型/provider 校验失败且 runtime 尚未开始时不计时。
- 在最终成功、失败或取消终态停止计时。一次运行中的模型请求、自动上下文压缩、工具调用及等待权限确认均计入墙钟耗时；工具续轮和重试不重置计时。
- 运行期间使用单调时钟累计 elapsed，避免系统时钟调整改变实时显示。到达终态时保存最终 elapsed 毫秒数，与对应 assistant turn 关联，供历史重载恢复。
- 进程异常退出而未持久化终态时，不根据重启时间倒推耗时，也不显示推测值；保留现有恢复/中断呈现。已有历史没有耗时字段时不合成时间。
- 显示向上取整到秒：不足 60 秒显示 `N 秒`；更长显示 `M 分 SS 秒`；达到一小时显示 `H 小时 M 分`。0 至不足 1 秒显示 `1 秒`。

## 交互

- 新一轮启动后，thinking 和该轮中间过程默认展开。增量到达时不得重置用户刚刚主动切换的展开状态。
- 成功、失败或取消终态各触发一次自动折叠；状态入口显示对应状态和总耗时，例如 `已完成 · 用时 10 秒`、`已失败 · 用时 10 秒`、`已停止 · 用时 10 秒`。失败原因或取消状态仍清楚可见，不能呈现为成功。
- 折叠只收起本轮中间过程；最终回答留在主时间线且不被折叠。入口可再次展开，展开后的长内容在有界内部区域滚动。
- 历史中有已保存耗时的终态默认显示为折叠入口；用户当前窗口内展开后可再次折叠。展开状态不作为运行数据持久化，重开应用后仍按终态默认折叠。
- 旧历史与没有终态耗时的中断运行不显示时长；不得用工具时长相加、消息时间差或当前时间伪造总耗时。

## 边界

- 复用 #103 有界滚动容器与 #70 工具活动结构，不重新设计工具分组或改变工具内容。
- PR #145/#71 的 provider reasoning summary 支持曾被明确暂缓；本卡不重新启用 Responses API，也不依赖 summary 标题。折叠入口使用本规格定义的状态与耗时。
- 不改变最终回复、权限判定、取消/失败原因、工具执行或压缩策略。
- 不新增 provider 请求，不记录 prompt、回复正文或工具输出以实现计时。

## 验收

1. 长 thinking 流式输出默认展开；用户手动折叠后，后续增量不抢回展开状态。纵向内容有界、可内部滚动，滚动位置不因新增量被强制拉回。
2. 包含多个 provider/工具轮次的一次运行只产生一个持续计时值；成功后显示耗时并自动折叠中间过程，最终回复仍可见，且可再次展开。
3. 权限等待期间时间继续累计；失败与取消以各自状态结束并折叠，原因/终态仍可见。
4. 切换会话、历史分页/重建及应用重启后，完成运行的耗时仍与正确 turn 关联并默认折叠；旧记录和无终态耗时的中断运行不显示伪造时间。
5. 用户终态后手动展开/折叠、短 thinking、没有 thinking、多轮相邻回答、浅/深色、窄窗口均无空白块、回复隐藏或布局跳动。
6. 新增/修改的测试覆盖计时口径、轮次关联、格式化、终态、终态持久化/历史恢复、旧记录回退和用户展开状态；仅运行本卡受影响包的定向 Nextest。云端 PR required check 仍为合并门禁。

## 实现边界

允许修改完成上述目标所需的 `vega_conversation`/`vega_store` 持久化投影、`vega_ui::conversation_stream` 展示状态、`vega` run 生命周期接线，以及相应测试和递增 migration。不得为测试扩大 production public API，不新增依赖，不新增代码注释。主 agent 负责本规格、审查和集成；专用实现子代理负责代码与定向测试。
