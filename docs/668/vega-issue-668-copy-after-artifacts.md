# #668 产物卡片后的复制入口

## 需求与根因

用户反馈：有产物卡片时复制按钮夹在正文与卡片之间。静态调用链：`flush_artifact_group` 在回复之后插入独立 `ArtifactGroup`，而 `copy_source_for_entry` 和渲染分支仅为 Assistant 生成复制页脚。

## 验收用例

- 完成回复有产物：复制入口只出现一次，位于同回合产物组下方，复制内容仍为原来的最终回复正文，不包含卡片路径或其他回合。
- 没有产物：原回复下方复制位置、文本与回执不变。
- Native 无可信 Final、失败回复及 Codex 失败/活动回复：不因产物出现而新增复制权限。
- 运行态继续隐藏入口；完成态 hover/focus、键盘与短回执复用现有控件。
- 产物异步到达或历史恢复：正文旧页脚不残留，卡片新页脚计入滚动估高与重新测量。
- 多回合互不串位；无正文产物组不凭空获得复制入口。

## 实现计划与验证边界

保留正文复制源判定；展示层把最后一个可复制正文的入口路由到同回合产物组。渲染与估高共用同一判定；追加产物时使旧页脚行失效。无新增依赖、文案、持久化或 Rust 测试。

本地仅静态检查，禁止执行 Vega、构建与测试。最终 head 经独立审查与 Actions required CI 后才能合并；真实位置、hover/focus、回执与滚动由用户手测确认。
