# 项目收起后恢复默认任务窗口

Issue: https://github.com/puzige/vega/issues/683

## 契约

- 接受成功且非过期的组织快照时，将其中已收起项目的非置顶任务窗口重置为 5。单项目收起不改其他展开项目；全部收起通过同一快照应用路径处理。
- 失败或被丢弃的旧响应不重置窗口。置顶和归档筛选不变。
- 被重置项目暂停自动滚动增长；重新展开、重绘、底部残留位置和已排队 defer 都不能解除暂停。
- 后续侧栏滚轮事件仅恢复当前展开项目的自动增长；Show more 仍增加一页并恢复该项目后续自动增长。收起期间滚动不解除该项目暂停。

## 实现

`organization.rs` 在成功快照应用处重置已收起项目，并以项目 ID 集合暂停增长；自动增长查询和实际增长均检查暂停状态。`sidebar/mod.rs` 的滚轮事件恢复展开项目的增长。没有新增界面文字、依赖或 Rust 测试。

## 静态验证与回归

本地仅运行 rustfmt 和 git diff --check，不运行 Vega、构建或测试。
静态检查覆盖单项目/全部收起共同成功路径、失败分支、旧 revision 拒绝、折叠期间滚动、重新展开和排队增长时暂停条件。

Actions 负责最终版本编译、Clippy、现存 Python 验证及 Rust 空集清点。真实交互待用户手测：多个项目各加载多页，单个收起后重新展开仅 5 条且其他项目不变；全部收起再展开各为 5 条；在侧栏底部/不足一屏时不自行追加；再次滚动或 Show more 可继续加载。CI 不替代此手测。
