# 更新胶囊固定 28px 高度

## 目标与边界

用户已授权实施 #825：主窗口更新入口固定为 28 个逻辑像素高，文字垂直居中，与右侧标题栏图标按钮齐高。仅取代 [#811 规格](../811/update-notice-capsule.md)中垂直内距撑开高度的规则，其他契约不变。右侧间距不在本卡范围。

## 验收用例

| 前置状态 / 操作 | 可观察结果 | 验证层级与状态 |
|---|---|---|
| Available / Ready，浅色或深色主题，中英文标签 | 胶囊高度均为 28px，文字垂直居中；宽度按标签适配，左右各 12px 内距，标签不裁切 | 静态布局核对、云端编译；实际观感待用户手测 |
| 默认、hover、按下、Tab 焦点 | 高度不变，保留主题色背景、配套前景、全圆角和原有状态反馈 | 静态差异核对；交互与视觉待用户手测 |
| 点击或 Enter / Space | 仍打开常规设置，不直接安装或重启 | 静态接线核对；真实交互待用户手测 |
| 隐藏条件成立或更新不处于 Available / Ready | 保持原显隐，不新增占位 | 静态差异核对；实际显示待用户手测 |
| 窄窗口、长标题 | 标题仍可截断，胶囊保持完整尺寸；不改变右侧控件组预留与间距 | 静态布局核对；真实布局待用户手测 |

## 实现计划

- 单一入口为 `crates/vega/src/window/render.rs::render_main_header` 的 `vega-update-notice`，Available / Ready 共用该路径。
- 高度复用现有 `Layout::TITLEBAR_CONTROL_SIZE`（28），去掉上下各 4px 内距，改用 flex 居中；禁止 flex 收缩以保留标签自适应宽度。
- 保留水平内距、13px 字号、颜色、圆角、状态反馈、显隐和所有事件处理；不改标题栏、主题 token、更新状态机、下载、安装或重启。

## 数值核对

| 项目 | 算式 / 结果 |
|---|---|
| 胶囊高度 | `TITLEBAR_CONTROL_SIZE = 28px`，与图标按钮同 token |
| 全圆角半径 | 高度的一半：`28 / 2 = 14px`（沿用 `rounded_full`） |
| 水平内距总和 | `12 + 12 = 24px`；总宽为标签自然宽度 + 24px |
| 垂直布局 | 固定高度 28px、上下内距 0；文字行盒通过 `items_center` 居中，不再依赖字高加 8px |
