# Issue #486 · Markdown 链接外观与完整悬停预览

状态：需求 v1 已冻结，2026-10-19；尚未实现、未验证功能。来源：[Issue #486](https://github.com/puzige/vega/issues/486)。

## 1. 目标与本轮裁决

阅读消息时能辨认链接及所属站点，在离开会话前查看目标网页的真实预览；预览失败不影响打开原链接。

用户本轮明确确认：

1. 正文链接使用**蓝色、Medium（500）字重、默认无下划线、hover 显示虚线、左侧内置站点图标**。
2. **本期包含完整悬停预览：站点、标题、摘要、图片和打开入口**，不延期为仅 URL 的轻量卡。

下文冻结覆盖范围、交互、数据真实性、失败回退和验收。延迟等细则是本规格采用的默认值，不将它们冒充用户原话。需求来源为用户可见截图和本轮明确选择，样式使用 Vega 自身设计语言及已许可资源；不采用第三方 bundle 解包得到的 CSS、内部 token、组件树或图标。旧取证评论不构成实现契约。

截图二可观察到的是链接附近的网页预览浮层，含站点、预览图、标题、摘要和 Open。仅凭截图不能证明参考产品内部的数据通路；本规格不沿用“必然由工具提供固定推荐卡”的结论。下文静态网页元信息方案是 Vega 的产品选择。

## 2. 覆盖范围

| 对象 | 外观、点击与键盘 | 完整网页预览 |
|---|---|---|
| 显式 Markdown 链接、`<https://…>`、已识别的裸 HTTP/HTTPS 地址 | 统一适用 | 适用 |
| 用户消息、模型回复、展开的思考；段落、标题、列表、引用、表格 | 统一适用 | 适用 |
| 共用正文链接渲染器的 Markdown 文件预览、更新说明 | 同一行为，不分叉 | 适用 |
| 已有显式 `mailto:` 链接 | 同一文字外观、邮件图标；保留打开邮件应用 | 不联网，卡内只展示邮件目标与打开入口 |
| 不支持的 scheme、相对地址、普通文本 | 保持不可交互文本，不增加站点图标或悬停反馈 | 不出现 |
| 围栏/缩进代码、普通行内代码中的 URL | 保持代码，不新增识别 | 不出现 |

显式链接标签原本含行内代码时，仍保持其既有等宽字体、代码底与显式链接目标；本卡不把普通代码中的 URL 变成链接。全局导航、工具记录中的对象名、本地文件引用及代码块头部不在本卡范围内。

## 3. 行内链接

### 3.1 外观与布局

- 链接文字使用现有浅/深主题的 `accent`，不改全局品牌色；常规正文链接的字重为 500。原文粗体、标题等更高字重保留，斜体与等宽语义保留。
- 默认没有下划线。指针进入该链接的图标或文字范围时显示细虚线；键盘聚焦时也显示虚线及可见焦点。虚线只覆盖标签文字，不画到图标、普通文字或整行空白上；不能用波浪线或实线交付。
- 图标与字重在初次布局时确定。hover、focus、预览加载和关闭只改变绘制/浮层状态，不改变正文尺寸、换行、行高或滚动位置，不在 hover 时重新 shaping 全段文字。
- 图标采用共享 16px 槽位，与文字视觉中线对齐，文字前间隔 4px；同一个链接自然折行时只在起始处显示一次图标。图标是装饰，不作为文本字节或独立焦点进入选择、复制与辅助技术朗读。
- 浅/深主题、CJK/Latin、相邻链接、跨行长 URL、表格窄列及显式代码标签均须成立。

### 3.2 站点识别

- 首期内置品牌映射必须覆盖 `github.com` 及其真实子域（例如 `gist.github.com`），复用 Vega 共享图标与已许可资产。其它 HTTP/HTTPS 站点使用通用 globe；邮件使用邮件图标。
- 图标取真实 URL 的 hostname，不取标签文字或网页自报的站点名；`github.com.example.org` 和 `https://github.com@example.org/` 都不得显示 GitHub 品牌。
- 图标随消息立即显示，不能等待网页预览请求。首期不联网获取 favicon，也不向第三方 favicon 服务提交链接。
- 后续增加其它品牌映射应明确列出域名与资产来源；本期不承诺覆盖全部站点品牌。

## 4. 完整预览浮层

### 4.1 触发与生命周期

- 在同一链接的图标或文字上稳定停留 **400ms** 后显示预览，并按需请求网页数据；快速划过不显示、不请求。键盘聚焦停留采用同样规则。
- 同一窗口同时最多显示一张卡。链接自然折行时，各片段属于同一目标；从片段移到另一片段不重复请求。相邻的不同链接必须按各自目标切换。
- 浮层锚定当前链接片段，优先放下方，空间不足则向上或向内避让，整体留在窗口可见范围；不参与正文排版，不推动阅读位置，不打开侧栏或新页面。
- 指针可从链接移入浮层并操作 Open；离开触发器与浮层后 **150ms** 关闭，跨过二者间的间隙不能导致卡片无法进入。键盘焦点仍在触发器/卡内时，单纯移开指针不关闭。
- Escape、外部点击、会话切换、正文滚动、链接卸载/目标变化、窗口失活立即关闭，并取消该卡未完成的工作。Escape 后在指针/焦点尚未重新进入前不自动弹回；普通相邻文本流式更新而目标未变时保持锚点稳定。
- 鼠标弹出不抢 Composer 或正文焦点。开始按下、拖选、多击或 Shift 扩选时先抑制预览，保留既有选择行为。

### 4.2 内容与排版

卡片按如下信息层级组织：

1. 顶部为站点图标、**实际目标主机名**及有文字的 **Open** 操作。
2. 网页提供可用预览图时显示图片，保持比例；只显示图片，不执行嵌入网页。无图不留空白图框。
3. 标题最多两行、摘要最多三行；文字允许选择复制，不把整张卡做成会误触打开的大按钮。
4. 原始目标完整地址可查看和复制，作为次级信息；主机名必须清楚可见。长地址可在局部展开，不撑破窗口或隐藏 Open。

圆角、边框、浮层底色、阴影、排版和间距进入共享主题 token，遵守设计守则。正常卡不添加“已生成预览”“包含若干字段”等说明。装载状态、可用内容和局部错误直接表达实际状态；成功后不再叠加 toast。

### 4.3 加载、缺失与失败

| 状态 | 可见结果与恢复 |
|---|---|
| 请求进行中 | 先显示真实域名、目标地址与可用的 Open；内容区域局部 loading，不阻塞点击原链接 |
| 元信息齐全 | 展示站点、真实标题、真实摘要、图片与 Open |
| 无摘要或图片 | 隐藏缺失项并自然收紧布局，保留其它真实字段 |
| 图片失败、格式不支持或过大 | 移除图片区；保留已取得的文字，不把整卡标为失败 |
| 页面没有可用标题 | 使用真实目标地址作为回退，不把原链接标签冒充网页标题 |
| 离线、超时、HTTP 错误或解析失败 | 卡内显示简短“无法加载预览”及 Retry，始终保留目标与 Open；不出全局错误弹窗 |
| 非网页、需登录页面或禁止抓取的地址 | 简短说明当前不能提供网页预览，保留目标与 Open；不反复自动尝试或申请登录权限 |

请求完成后只更新仍对应同一目标的卡；旧目标的迟到结果不得覆盖新目标。关闭卡后即使取得结果，也不能重新弹卡或打开浏览器。

## 5. 点击、选择与键盘

- 原链接的有效单击仍打开原始目标一次，保留 #357 的 500ms 多击仲裁、4px 点击容差与取消规则。拖选、双击/三击、Shift 扩选、右键、不同目标间按下/抬起、失焦、文本身份变化均不得误打开。
- 图标与标签是同一个链接命中对象，不能因有两个元素而打开两次。图标区域不吞掉从文字开始的拖选；选文复制不包含图标、虚线、预览内容或额外 URL；“复制原文”仍保留用户完整源文。
- 卡片的 Open 是独立明确操作，点击或键盘激活只打开原始目标一次；不把 hover、图片加载或卡片出现当成打开操作。链接本身的点击不依赖预览成功。
- 共享正文阅读区域提供链接键盘焦点，按可见内容顺序导航；Enter 打开链接，聚焦停留可出现同一预览。触发器与卡内 Open/Retry 可用键盘访问，Escape 关闭，非模态卡不困住焦点。
- 键盘关闭浮层后保留触发链接焦点；若触发器已经卸载，回到仍存在的阅读区域，不意外聚焦 Composer 或跳到其它会话。鼠标打开的卡关闭时不改动原焦点。
- 链接有链接语义、清楚的标签及可供辅助技术读取的目标；图标不重复朗读，Open/Retry 有可访问名称，关键信息不只通过颜色、虚线或 hover 表达。

## 6. 预览数据与联网边界

- 本期完整预览针对**可匿名访问的 HTTP/HTTPS 网页**。从静态 HTML 的 Open Graph 元信息读取标题、摘要和图片，分别允许回退到标准 `title`、`meta description`；图片没有可用元信息时不扫描正文任意图片。
- 正确处理属性顺序、HTML entity、相对图片地址、缺失/重复字段与无效 HTML；展示内容为有长度上界的纯文本。不得执行脚本、加载 iframe、启动无头浏览器截图或用模型编造摘要。
- 只在明确 hover/focus 触发后异步访问目标站及选定的预览图；消息到达、流式更新、历史恢复、滚动经过和绘制本身不触发批量抓取。联网不能放在 UI 绘制主线程。
- 不使用浏览器登录态、Cookie、GitHub Token、Provider/MCP 凭据或第三方代理。401/403/登录墙按不可预览回退；不申请额外账号权限。本期不接 GitHub API，不承诺私有 Issue 的图片、评论数、作者和时间等富数据。
- 自动抓取只允许公网目标；带 userinfo 的 URL、localhost、回环、私网、链路本地及其它非公网地址不抓取。每次重定向及图片 URL 均重新检查；DNS 结果与实际连接一致，不能只检查字符串或初次解析后任由重绑定。
- 自动预览限制不改变用户主动点击的既有打开规则。抓取去掉 fragment，保留页面所需 query；Open 使用原始完整 URL。发生跨站重定向时须显示最终主机及原始目标，不能用原站图标为另一站背书。
- 网页和图片必须有总超时、重定向次数、响应字节、图像解码尺寸及缓存内存上界。重复目标合并进行中的请求，使用有容量/有效期上界的内存缓存；失败短期缓存，Retry 可主动重新尝试；切换会话不带来无界后台工作。
- 本期不落库，不改会话原文/持久化，不把预览放进模型上下文或费用统计；不记录完整 URL、query、网页正文或认证信息到日志。卡片关闭不撤回已完成的网络请求，不宣称从未访问目标站。

## 9. 后续技术设计与工作流

本轮只定需求并发布规格。源码审查基线为 `f054c35874513bab4c65d7e179fdac6758503182`；已有 `StreamSpan.link`、`links.rs::register_link_interactions/link_regions`、可选/普通文本及 inline-code 路径可用于下一步设计。当前已存在链接点击能力，本卡包含展示契约变更与新增预览能力，按 Feature 组织后续工作，不把需求差异伪装成旧代码违反旧规格。

预期影响：`vega_ui` 的正文布局/命中/绘制、共享图标与主题 token；异步预览服务及跨 crate 类型须守现有层次，`vega_runtime` 不得依赖 UI。不能从截图推导不存在的接口，不能向 `StyledText` 填装饰字节破坏选择索引。
