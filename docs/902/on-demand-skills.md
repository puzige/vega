# #902 调查中按需加载 Skill

## 授权与验收（v3）

用户已批准设置启用后在调查中按需加载，并要求回归测试及非实现者独立审查。取代评估 v1 的候选预留建议；不创建逐任务预留或批准流程，不修改用户设置、Skill 文件或工具权限。基线 `d36ce592c26450a0d243f77bec9bbaa11dc2e546`。

| 前置与操作 | 可观察结果 | 验证 |
| --- | --- | --- |
| 直接用户任务：读取普通文件后调用 load_skill | 已启用且符合自动选择设置的项成功加载，后续模型请求包含正文 | 云端真实 runtime 循环回归 |
| 首轮加载、重复加载 | loaded / already_loaded，正文不重复、不热替换 | 云端行为回归 |
| 逐项关闭、全局/来源/项目禁用或 automatic 关闭 | 不进入自动选择目录或拒绝加载；模型不能打开设置 | 云端目录/行为回归，设置链静态核对 |
| 未激活资源、源文件/SHA/链接目标变化、取消 | 不读未激活资源、拒绝新激活、不悄悄换副本 | 云端行为回归 |
| 任务中撤权 | authority probe 使循环停止；不再向 Provider 注入新正文或执行后续工具 | 云端真实循环回归 |
| 非直接用户来源 | 保留 run 级 direct_user 拒绝；定时/委派/恢复不因本修复获得新资格 | 云端行为回归 + 入口静态核对 |
| Skill 指导写文件，当前 ReadOnly | 写入仍拒绝，目标不存在 | 云端真实权限循环回归 |
| 混合加载和普通操作、超过三项、预算不足 | 普通操作仍拒绝；上限/预算保持；加载失败不激活 | 云端行为回归 |
| 工具结果诱导加载 | 可以选择已启用目录中的项（明确残余风险）；不能加载禁用/未知项，不能改变权限 | 云端边界回归 + 人工风险说明 |
| 立即引导、冻结恢复 | 沿用暂存/持久化后切换和历史只读展示；不新增激活授权 | 静态差异审查 |

以上是验收要求，不代表已执行通过。原生集成由用户手测。

## 实现方案

移除 `direct_user_skill_round` 及 `load_model_for_round` 的轮次参数，runtime 调用已有 `SkillRun::load_model`。保留 run 级 `direct_user`、catalog automatic gate、启用筛选、来源/SHA/链接目标验证、authority probe、owner/route 围栏、取消、冻结正文/资源、激活上限 3 和预算。更新模型目录提示为任务中按需加载，不再要求先于普通工具。`not_direct_user` 只用于真正非直接用户 run，不再代表工具调用顺序。

设置语义保持现有层级：逐项 enabled 是必要条件，项目项受项目 enabled/automatic 控制，全局与导入项受 global_enabled/automatic_enabled 控制，来源 enabled/automatic 同样有效。单项 UI 开关已同时写 enabled/automatic；关闭自动选择不等于允许模型自动加载。精确 UI 选择仍沿用原有显式路径，不由模型绕过 automatic gate。运行开始冻结目录不热刷新；运行中设置变化继续触发 generation 撤权/取消，后续新任务重新读取设置，不把“随时”解释为修改当前冻结身份。

不改变混合批次、工具定义、sandbox、危险命令/网络/凭据授权和确认机制。Skill 是低信任指导而非工具授权，allowed-tools 仍是 inert metadata。

## 安全取舍与回滚

启用意味着允许在既有目录与设置边界内随时按需激活，不证明内容无害或选择动机正确。网页/工具结果可能诱导加载不必要但已启用的 Skill，来源/SHA 无法判定这种动机；本修复不宣称阻止全部提示注入。低信任输入不能打开设置、增加来源、替换身份或授予工具权限。

无新依赖、配置、表结构或确认 UI。必要开发测试在现有 Actions 执行并固定源码/完整 SHA/日志，合并前清除测试和独占接线，最终 head 跑完整 required CI；空集不冒充行为测试通过。独立审查绑定停写版本。回滚可恢复旧时机门槛，但不重放旧调用、不热换已激活快照。
