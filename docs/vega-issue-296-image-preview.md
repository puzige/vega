## 冻结契约

### P01 所有现有图片入口

- Composer 缩略图、UserImages 中每张图片、每个已交付截图的图片本体，左键点击或 Enter/Space 均发起相同的右侧预览。入口有实际焦点、可访问名称和 hover/focus 反馈；移除/保存按钮操作不能同时触发图片打开。
- 点击来源携带当前 stream、所属 task/route 和不可混淆的 occurrence 身份：草稿附件 ID、历史消息/entry 身份及图片序号、截图所属 entry/call。相同 bytes 的两个图片实例仍分别绑定各自来源，不能用内容 hash 代替 UI 所有权。
- 图片准备尚未完成时也可打开并显示加载状态；使用同一已验证原图异步准备，不在渲染/输入关键路径进行文件 IO 或图像解码。
- 会话过程折叠、Final 自动收起等原规则继续有效；只要图片本体可见，其点击方式一致。原截图卡片的行内保存入口保留。

### P02 右侧 Workspace

- 每个当前会话使用一个可复用的图片预览页；点击另一张图替换该页对象并显示对应图，重复点击同一图只激活，不增殖页签。其它文件、Review、Terminal 页签及其状态保留。
- 每次图片点击均激活右侧 Workspace 并使其可见；即使图片页曾通过已有 Workspace 操作移动到底部，也移回右侧。沿用工作区尺寸、拖拽、页签关闭和显隐控件。
- 可用宽度满足现有610逻辑像素守卫时正常右侧分栏；不足时临时最大化图片所在右侧 Workspace，使动作始终有可见结果。关闭此临时图片预览或窗口重新具备分栏空间时恢复此前 dock 状态，不永久改变其它页签的用户最大化选择。此前底部最大化时，宽窗临时改为可同时看见聊天和右栏的分栏，关闭图片才恢复底部最大化；从窄窗拉宽也保持这段临时分栏，避免底部再次遮住图片。用户主动切换最大化则采用其新选择。
- 预览是非模态面板，聊天可继续滚动、选择和输入；不加背景遮罩，不拦截外部点击，不把 Tab 限在图片内。关闭页签或预览内 Escape 关闭图片页；只有预览/其菜单实际持焦时处理 Escape，不能吞掉 Composer 或其它面板的 Escape。
- 打开后焦点进入预览；关闭时原来源仍有效且缩略图仍在当前可见区域则回焦缩略图，否则回到当前会话并保持阅读位置，不为回焦强制滚动去寻找虚拟化卸载的来源。来源失效或切换任务时清理预览及菜单，不把旧来源焦点带到新任务。正文因分栏变窄时沿用实际重测和原身份阅读锚点恢复：保持同一项与非跟尾状态；按现有GPUI重测契约，重排项保持项内相对位置，固定高度项保持绝对偏移。

### P03 图片与顶栏

- 顶栏高40，水平内距12，操作间距8，控件高28，图标16；沿用共享 Layout/Typography/ThemeColors，没有局部硬编码颜色。左侧文件名可收缩/省略并有完整 tooltip，右侧“打开方式”下拉与“保存到本地”图标始终可达，文件名不挤出操作。
- 对没有原名的现有图片使用稳定且内容无关的派生名称，例如“图片-1.png”/“截图-1.png”；后缀按真实 MIME 为 png/jpg/webp。名称表达本图片的导出名，不宣称恢复原文件名，不展示内部绝对路径，不新增 schema。
- 主区使用低强调主题背景，内距16，图片居中完整 contain、不裁剪、保持比例，默认不超过原尺寸放大。大图随实际面板内容尺寸缩小；小图保持原尺寸。加载与出错状态有明确文案，异步结果只更新所属图片。浅深主题均用现有 token。
- 本轮不新增缩放工具栏、轮播、编辑或图片管理器。顶栏保存/打开状态就近反馈，状态不得覆盖图片或挤动聊天中的原卡片。

几何核算：宽320面板去两侧12后可用296；保存28、打开方式控件约104、三个相邻控件之间共两处8间距，文件名余296-28-104-16=148，允许省略。高600面板减40顶栏与上下16后内容高528，内容宽288；1200×800按min(288/1200,528/800,1)=0.24显示288×192；16×8保持16×8。外层Workspace页签高度仍由现有宿主管理，不叠算为图片区域。

### P04 保存到本地

- 复用原生路径选择器与 `attachments::save_screenshot` 的已验证原图保存链路：MIME对应默认后缀，精确编码 bytes，不重编码，不写入项目，不用显示名拼接任意路径。
- 一个图片操作一次 pending；忙态阻止重复派发。取消不报错、零写入；已有文件不覆盖；失败/成功只反馈到同一图片。保留 create_new、0600、O_NOFOLLOW/O_NONBLOCK 与后台有界写入。
- 选择器返回后、开始写入前核对当前图片和来源；来源失效/切图/关闭后不启动尚未开始的导出。已开始的异步写入仅处理用户刚选择的目标，不把结果或提示投递到新图/新会话。
- 原截图行内保存无需先打开预览：一般核对自身 card/stream/route；若发起时该图正是当前预览，则同时捕获其预览代次，后续关闭/切图也取消尚未启动的导出。行内与面板入口共用同图 busy，不能跨入口重复弹 picker。

### P05 真实打开方式

- 用户点击“打开方式”才为已验证图片创建应用拥有的临时文件，并向 macOS 查询实际可处理该文件的应用；下拉仅显示真实返回的应用名称，系统默认项可标“默认”。不能用硬编码或无动作条目冒充应用选择。空列表/查询失败有就近提示，保存仍可用。
- App 层负责临时文件与平台适配，复用当前已有生产依赖 tempfile/libc；不新增依赖。使用 owner-only 临时目录与正确 MIME 后缀，写入原始 bytes；不让模型、显示文件名或远程URL决定文件路径。
- 可采用小型 cfg(macos) NSWorkspace 应用枚举适配及现有 raw ObjC/AppKit FFI 模式。本机 SDK/generated bindings 的 NSWorkspace 继承 NSObject 的 AnyThread、无 MainThreadOnly 限制；后台调用自建 autorelease pool，在同一同步调用内完成枚举并复制为 owned Rust 名称/路径，不让 ObjC 指针跨线程或 await。项目仍支持 macOS 11，而该枚举 API 从12起可用，调用前必须检查 selector 可用性；旧系统缺少接口时就近提示无法查询打开方式，保存保持可用，不崩溃、不伪造列表。文件 IO、校验、清理及进程等待不得阻塞 UI；GPUI 菜单和原生 picker 回主线程，异步结果受请求序号和来源校验。
- 选择项只能引用刚枚举出的应用标识/完整 bundle 路径；后台固定 `/usr/bin/open`，按参数向量 `-a <app bundle> -- <owned image>` 派发，不经过 shell，不修改默认关联，不自动打开应用。启动器沿用有界等待/取消的工程约定；报成功只表示系统已接受打开请求，不表示外部应用已完成解码。
- 临时文件生命周期长于预览页：启动器实际 spawn/发起系统调用后即保留至本次 Vega 应用会话正常退出，包括超时或取消后交接结果不确定的情况，不能关面板或切图即删。相同来源且临时文件仍为原 bytes 时可复用；后台校验发现外部应用改写后创建新版本并计入配额，不覆盖已交接的旧文件。确认未发起打开的临时资源可在请求取消/失效时回收，保存始终取不可变附件 bytes。
- 应用会话缓存最多32份且总编码 bytes最多128MiB，以先到上限为准；配额包含 pending/reserved/pinned，物化前原子预留，失败或未启动即取消时释放（单张既有8MiB上限，最坏只能容纳16张8MiB图片）。达到上限不暗中删除仍可能被外部应用读取的文件，仍可重开已有原图缓存或保存到本地，提示先保存再打开。没有自动后台导出或观察历史缓存；只保证正常退出清理，不宣称进程崩溃残留已清理。
- 使用进程内系统应用枚举/启动器替身测试错误、取消、无应用、精确一次 argv 与文件生命周期；真实 macOS 关联和外部应用验收由用户手测，不调用真实应用制造自动门禁。

### P06 生命周期、边界与旧行为

- 所属草稿图片移除/发送消耗、所属历史 entry 离开加载窗口、截图 card 被移除、route/stream 变化时关闭图片页，取消未派发动作并丢弃迟到结果。新导入图片不能使仍存在的其它草稿图片错误失效。历史同一来源若被重建，至少不能继续持有已失效旧来源；原存储/持久化/去重不变。
- 图片预览只能接收已验证 ImageAttachment 与可信来源描述，不通过 raw path 或 URL 绕过文件/产物服务。跨模块事件遵循现有 UI event/controller 接线方式；业务共享类型仍经 conversation::types，不把 GPUI 引入 runtime。
- 不修改 provider、工具、权限、数据库、导入/历史数量及解码预算；不将预览图片重新发给模型。其它 Workspace 页签、终端任务身份、输入草稿、Markdown 选择和阅读定位保留。
- 不新增代码注释、非测试 unwrap/expect、通用任意文件打开能力。若平台API或所有权条件与规格矛盾，先向主控反馈事实并裁定。

- 既有图片名称、预览顶栏“打开方式”与保存入口、图片存储/排序/去重、应用缓存/临时文件、runtime、权限、数据库与依赖不改变。保存结果提示不在本次删除范围；不把其它产品状态随之清理。
