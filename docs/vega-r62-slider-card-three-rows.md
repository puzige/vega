# R62 · 滑块卡片改为 Codex 三行布局（规格冻结）

> 状态：**SPEC FROZEN**
> 基线：`master @ a6ca3d5`
> 用户决策（2026-09-14）：**选 B**（允许重叠，但要"浮在上层"的视觉）；**去掉闪电图标**；**档位名与模型名改为上下两级**
> 前置：R57（滑块）+ R58（Off 档）+ R59（两级下钻）+ R61（触发器锚定）

---

## §1 问题

R61 让卡片紧贴模型触发器后，卡片与 composer 卡片**物理重叠**。用户实机反馈两个现象：

| # | 现象 | 真实根因 |
|---|---|---|
| **D1** | 卡片看起来"半透明"，placeholder 文字穿过卡片 | **不是半透明**——卡片背景是 `bg_elevated = #FFFFFFFF`（纯白不透明）。是**阴影太弱**（`shadow_sm()`），重叠时看不出"浮在上层"，composer 卡片的上边框横穿卡片 |
| **D2** | 卡片左侧"被切掉" | 同上：composer 卡片的圆角边缘与滑块卡片交错 |

**用户决策**：接受重叠（选 B），但要求视觉上明确"浮在上层"，并**按参考实现的卡片结构改造**。

## §2 参考实现的卡片结构（用户截图实证）

**三行，逐行垂直排列**：

```
        Max  >              ← 第1行：档位名（蓝/紫，随强度）+ chevron，居中
     GPT-5.6 Luna           ← 第2行：模型名（灰），居中
  [●●●◉○○○]                ← 第3行：滑块轨道
```

**与 Vega 当前的差异**：

| 项 | 参考实现 | Vega 现状 |
|---|---|---|
| 行数 | **3 行** | 2 行（档位名与模型名**挤在同一行**） |
| 左侧闪电图标 | **无** | **有**（`bolt_icon`） |
| 档位名位置 | 第 1 行，**居中** | 与模型名同行，偏右 |
| 模型名位置 | 第 2 行，**居中** | 与档位名同行 |
| 卡片高度 | 更高（3 行） | 较矮（2 行） |

## §3 契约

### R1（必须）移除闪电图标

删除卡片标题行的 `bolt_icon`（`thinking_slider.rs` 标题行第一个 child）。
`BOLT_SVG` 常量若因此无引用，一并删除。

### R2（必须）改为三行垂直布局

卡片内容自上而下：

| 行 | 内容 | 对齐 | 颜色 |
|---|---|---|---|
| 1 | 档位名 + `>` chevron | **居中** | 档位名用强度色（R57 §3.4 R8 的 ramp），chevron 用 `text_tertiary` |
| 2 | 模型名 | **居中** | `text_secondary`（次级灰） |
| 3 | 滑块轨道 | 满宽 | — |

**行间距**：用 `CARD_ROW_GAP`（现有 8.0）或按视觉调整，实现者在报告中说明。

### R3（必须）保留两级下钻语义

- 第 1 行（档位名 + chevron）仍是**打开模型列表**的入口（`ThinkingSliderTitleActivated`）
- 第 2 行（模型名）**不响应点击**（或与第 1 行同区域——由实现者判断，需在报告中说明）
- 若将两行合并为同一可点区域，**不得**改变 `ThinkingSliderTitleActivated` 的语义

### R4（必须）加强阴影，使"浮在上层"可辨

当前 `shadow_sm()` 太弱。改为更强的阴影。

**实现注记**（已核实）：
- `shadow_sm()` 是 **GPUI 框架自带**的方法，不是 Vega 定义的 token。多个组件在用：`command_palette.rs:237`、`threads_block.rs:1462`、`organization/menu.rs:195`、`branch_selector.rs:732`、`composer_actions.rs:557`。
- Vega **没有** `shadow_md` / `shadow_lg` 这类封装（已确认不存在）。
- GPUI 框架提供 `shadow_sm` / `shadow_md` / `shadow_lg` 等档位，可直接换用。

**判据**：卡片与 composer 卡片重叠处，**必须能明确分辨卡片在上层**——即重叠区域的边界处有可见的阴影过渡。

**不得**通过改背景为半透明来"解决"——背景应保持不透明（`bg_elevated`）。

### R5（必须）卡片高度变化不得破坏 R61 的锚定

R61 的锚定是「卡片下缘贴触发器上缘，间隙 8px」。三行布局会让卡片**变高**，但**锚定关系不变**——卡片向上生长，遮挡 utility bar 更多（用户已接受）。

### R6（必须）卡片宽度不变

保持 `THINKING_CARD_WIDTH = 254.5`。三行布局下，模型名与档位名各自 `min_w_0` + `truncate`，防止长名溢出。

## §4 明确不做

- 不改为半透明背景
- 不改两级下钻语义（R59）
- 不改 Off 档语义（R58）
- 不改底部行形态（R57）
- 不改 `reasoning.toml` / wire 编码
- 不缩小卡片

# R62 扩展 · 权限下拉 + utility bar 列表美化

> 用户实机反馈（2026-09-14），两项追加。同属 composer 区域 UI 对齐。

## §7 问题 A：`⚠ 确认` 点击无反应（功能缺陷）

### 现象

用户点击底部行的 `⚠ 确认`，**无任何反应**。

### 根因（代码核实）

`render_permission_status`（`crates/vega_ui/src/conversation_stream/render.rs:306-327`）**零交互处理**——无 `on_mouse_up`、无 `cursor_pointer`。

**这是 R57 P2b 的设计决定**：当时把 `确认` 从下拉改成静态文本，理由是"参考实现里 `Full access` 是静态的"。

**该判断错误**。用户实测截图证明：**`Full access` 是可点的**，点开是三行下拉：

```
How should ChatGPT actions be approved?          Learn more
  ✋ Ask for approval
     Always ask to edit external files and use the internet
  🛡 Approve for me
     Only ask for actions detected as potentially unsafe
  ⚠ Full access                                  ✓
     Unrestricted access to the internet and any file on your computer
```

**我的错误链条**：读到源码里的 `shouldShowFullAccessWarning`（一个警告提示）就断定权限不可点，**没有看实机**。这与之前误判"utility bar 在会话中常驻"是同一类错误。

### 契约

**R7（必须）** `⚠ 确认` 改为**可点击**，打开权限选择下拉。

**R8（必须）** 下拉内容对齐参考实现：

| 行 | 图标 | 标题 | 描述 |
|---|---|---|---|
| 1 | 手掌 | `只读`（Ask for approval 对应） | 每次都询问 |
| 2 | 盾牌 | `确认`（Approve for me 对应） | 仅对潜在不安全操作询问 |
| 3 | 警示 | `自动`（Full access 对应） | 不受限访问 |

- 顶部有标题行（参考实现为 `How should ChatGPT actions be approved?`；中文由实现者按现有 i18n 惯例处理）
- **当前选中项带勾选标记**
- 第 3 项（`自动`/Full access 对应）用 `warning` 色（参考实现是橙色）

**R9（必须）** `+` 菜单里的权限组**保留**（P1 加的），作为第二入口——两处都能改，且状态一致。

## §8 问题 B：utility bar 两个下拉太丑

### 现象（用户截图对比）

| | 参考实现 | Vega 现状 |
|---|---|---|
| 搜索框 | ✅ `🔍 Search projects` | ❌ 无 |
| 行图标 | ✅ 文件夹图标 | ❌ 纯文字 |
| 选中标记 | ✅ 右侧勾选 | ⚠️ 仅蓝字 |
| 分隔线 | ✅ 有 | ❌ 无 |
| 额外操作 | ✅ `+ New project` / `× Don't work in a project` | ❌ 无 |
| 选中行背景 | ✅ 浅灰圆角 | ❌ 无 |

**根因**：Vega 的两个下拉是**裸文字列表**，缺少列表应有的结构元素。

### 契约

**R10（必须）** 项目下拉与分支下拉按参考实现补齐：

1. **搜索框**（顶部，带放大镜图标 + placeholder）
2. **每行带图标**（项目 = 文件夹；分支 = 分支图标）
3. **当前选中项**：右侧勾选标记 + 浅灰圆角背景
4. **分隔线**（分组之间）
5. **额外操作项**（项目下拉：`+ 新建项目` / `× 不关联项目`；分支下拉：`+ 新建并切换分支`）

**R11（必须）** 保留既有语义：
- 选中项目/分支的行为不变（R49 契约）
- 搜索过滤不得改变"选中即切换"的语义
- 若某额外操作（如"新建项目"）当前无实现，**渲染但置灰**并标注，不得静默忽略
