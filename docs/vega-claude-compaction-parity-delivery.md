## Changes and source decisions

- `crates/vega_conversation/src/agent/compaction.rs`: direct role-preserving historical request, complete assistant/tool-result rounds, prior checkpoint as source, output allowance `min(20000, configured reserve)`, image markers, no fixed-byte stages/reducer or Length splitting. Only explicit input-overflow classification permits at most three oldest-round trims, counting local preflight and provider retries together. One truncation marker stays outside regrouping. Successful output must fit the final target without slicing or another reduction request.
- `crates/vega_conversation/src/agent/pipeline.rs`: one deterministic historical-image reconstruction for immediate result, normal send, displayed estimate and reload. Newest atomic image/text groups fit a 64000 estimated-token allowance; older omissions are explicit and every source image is validated. The newest live suffix remains exact.
- `crates/vega_runtime/src/agent/loop_.rs` and `context.rs`: recoverable soft-threshold compaction failure records real usage/failure and continues unchanged primary history only within the hard budget. Ordinary and skill-prospect attempts share a three-failure run-local circuit. Success resets it; a new run starts fresh. `InvalidProjection` distinguishes terminal corrupt source/authority from malformed provider summary output. Auth, credential guards, status-less transport/protocol errors, source/CAS/store errors and cancellation stay terminal.
- Conversation failure handling rechecks source, exact model and predecessor after *any* failed asynchronous operation, including complete-but-over-target output. Changed source cannot become permission to continue stale history. Known usage survives this error reclassification.
- Regression changes are in `agent/tests/history_permissions.rs`, compaction unit tests and runtime `agent/tests/claude_compaction.rs`. Prior fixed-byte/512-attempt/independent-stage assertions were replaced only where the frozen contract changed; full source/tool identity, raw audit, cancellation, billing and predecessor protections remain asserted.

Reference behavior comes from the owner-provided Claude Code 2.1.88 source-map modules `compact.ts`, `grouping.ts`, `prompt.ts` and `autoCompact.ts`. The port selects the ordinary streaming path, complete API-round PTL recovery and automatic failure circuit. Vega tool text offsets provide complete projected rounds because one stored assistant row may span several API calls. A narrow status400/413 recognizer accepts known structured context codes or anchored context-input phrases; generic errors and output Length do not qualify.

Explicit adaptations: existing80%/60% settings remain; Vega has no authoritative model maximum beyond its configured reserve; output is bounded at128KiB;60-second request and180-second operation deadlines are Vega safeguards. Provider transport retries remain separately bounded beneath a logical request. Reasoning is disabled only when the frozen profile permits it.64000-token image replay is a Vega extension. Runtime-owned system/tools/skills/MCP/permissions continue through their existing production paths, never from summary authority. Cache-sharing forks, cache-edit microcompaction, session-memory extraction and arbitrary file restoration are not implemented.

## Residuals and handoff

- Image preservation and image understanding are separate. The configured real model's visual-color task remains failed; the current evidence does not locate the cause beyond successful request reconstruction and serializer source inspection.
- PTL recovery deliberately omits oldest historical request groups with a marker. Raw transcript/audit stay authoritative, but omitted facts may not survive the model summary. No claim of lossless compression.
- Configured estimates are conservative, including image bytes; irreducible current suffix, oversized final summary, unsupported budgets, or corrupt media can still fail safely.
- Status-less network errors remain terminal to avoid treating credential/projection guard failures as soft failures.
- Native signed-app acceptance, packaging/install identity and any repository integration are main-agent responsibilities and are not claimed by these headless tests. The external final manifest and native evidence identify completed follow-up work.
