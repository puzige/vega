# 更新入口主题色胶囊

## 用户目标与范围

将主窗口右上角 `Update ready` 入口从透明底文字按钮改为主题色背景胶囊。仅改主窗口更新入口的视觉样式，不改更新状态机、下载、签名校验、安装、任务保护或重启行为。

## 实现契约

- `Available` 与 `Ready` 共用现有入口，保留原文案及显隐条件。
- 使用 `brand_primary` 实心背景、`brand_on_accent` 前景色与 `rounded_full` 全圆角，浅/深主题均从现有主题 token 获取颜色。
- 水平内距采用 12px，垂直内距沿用 4px，保留现有字号；不改标题栏高度或窗口控制预留区。
- hover、按下及键盘焦点时使用 `brand_primary_strong` 背景，确保交互状态仍可辨识。
- 保留点击、Tab 聚焦及 Enter/Space 打开常规设置的现有接线。不增加图标、提示文案或确认步骤。

## 验证与交付边界

- 本地仅执行差异与格式静态检查，不运行 Vega、编译、构建、打包或测试。
- 无业务逻辑变化，不为纯样式改动新增 Rust 测试。提交交由非实现者独立审查，并通过最终 head 的 required CI 后合并。
- 用户手测覆盖浅/深主题、默认/悬停/按下/键盘焦点、Available/Ready 文案以及点击和 Enter/Space 打开更新设置。CI 不替代用户视觉验收。
