# #716 · 启动加载态统一

## 契约
正常启动只显示现有透明 Vega Logo 的 shimmer，无可见标题、状态文字、重试或退出按钮。根容器占满窗口内容区域，Logo 为唯一布局子项，水平与垂直居中；不是侧栏之外的对话区域居中。保留无障碍加载标签和系统关闭窗口/Cmd-Q。

失败时移除 Logo/动画，保留现有具体错误及重试、退出操作和键盘焦点。重试重置动画时钟并移走失败按钮焦点，成功直接进入 workspace，不人为延长启动。启动恢复、权限重置、数据库逻辑不变。

## 最小实现
- 将 window/conversation_loading.rs 的 loading_logo 提取为应用级共享 loading_logo.rs；对话加载调用共享实现，不改其150ms阈值及路由状态。
- StartupView 加载分支只包含共享 Logo，失败分支保留原错误UI；加载焦点单独挂到根元素，Tab不访问隐藏按钮。
- 在创建启动窗口前安装系统动效设置；启动窗口激活时重新读取，减少动态效果/失焦静态显示。
- 不改Logo原始几何、颜色token、尺寸、扫光周期，无新依赖。居中按完整透明SVG画布布局，保留现有品牌内部几何，不添加人为像素偏移。

## 验证与交付
本地仅cargo fmt及git diff --check等静态检查，不运行Vega、编译或测试。风险集中在启动状态分支、焦点和共享绘制接线，通过静态独立审查及最终head Actions检查；不新增临时Rust测试。用户手测正常/慢启动、失败/重试/退出、键盘、浅深主题、减少动态效果与失焦、窗口缩放下居中，对话加载不回归。CI通过不代表视觉或性能验收。
