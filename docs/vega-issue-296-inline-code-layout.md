# Issue #296 · 行内代码与表格阅读排版

2026-10-13 用户追加：Vega 表格中的代码底色厚重、换行拥挤，要求参考所附 Codex 正文截图。第一张是行内代码而非 fenced code。本轮依据截图可见形态形成 Vega 自有实现，不读取第三方 bundle 内部 CSS、组件或资产，不发布原始截图及会话。

## 已核实的原因与范围

- `render_rows::apply_span_style` 的 Code 背景交给 GPUI run background，实际铺满行盒且为直角。`TextRun` 不带独立字号，所以写入 Code 的字号不决定单个 run 的字形大小；现正文实际为 `Typography::CONVERSATION = 13.5`、行高 23。
- 所有 inline spans 在同一段文字布局中，样式边界不额外插入换行。当前 parser 的 SoftBreak / HardBreak 及 #147 复制规则不改，不凭截图猜造原文。
- selectable / non-selectable 两条表格路径均等分列宽，短文件列占用过多空间。未实测表格估高又只计算空 `line.spans`，需让同一列分配进入表格估高，避免修改布局后继续按一行估算。

只涉及共享 Markdown 行内代码绘制、表格列分配、相关估高与测试；已复用 renderer 的思考、文件预览和更新说明沿用一致样式，不改它们的其它功能。fenced code 的样式、语法高亮、原始换行/缩进、横向滚动保留，不新增代码运行或链接行为。

本页替代 #59 I59-R5 的“等宽列/平分可用宽度”，保留共享列边界、每列最小 120px 和局部横向滚动；表格 padding 沿用 #296 v3 的 12/8（最小内容宽因此是 120−24=96）。细化 #296 v3 §5 的行内代码基线与轻底色要求。#147 的选择、复制、绘制顺序及 #119 的语法/内容保真不变。

## 冻结契约

1. C01 圆角底：行内代码保留等宽字形、继承当前段落字形大小/基线，不通过更改无效的 TextRun 字号宣称缩小。继续使用 `conversation_code` 的浅深主题色；背景高为 `min(实际字体大小 + 4, 实际行高)`，在每个视觉行内垂直居中，小圆角 4px。4px 留白与圆角进入共享 Layout token；不设边框/阴影，不撑高行盒。
2. C02 连续排版：背景按 code run 在各视觉行的实际文字范围绘制，包含换行前后每个片段及四角；不把中间所有行画成一整块，不扩展到相邻普通文字或标点。短 code 不拆为独立 nowrap 控件，超长标识符继续参与原段落宽度内的自然换行。不向显示或复制文本注入装饰空格、断字字符或换行。相邻 code、CJK/emoji、链接/强调与空内容均保持原顺序。
3. C03 选择优先：共享代码底始终在选区下面，随后绘制文字；完整/局部选中时保留 #147 的真实输入、精确剪贴板及有序绘制采样断言。两条 renderer 共用同一代码底实现，避免普通正文和会话正文样式分叉。宽度、字体与文本更新后的选择失效和命中几何不变。
4. C04 按内容分配列：表头和所有数据行共享同一组权重。每列以最长单元格物理行的展示宽度估计需求，加左右 padding 后夹取到 `[120, 480]`；估计复用现有 Unicode display-width 规则及 `CONVERSATION × 0.56`，用于分配空间，不代替 GPUI 实际字形断行。权重为 `max(需求−120, CONVERSATION)`。表格宽 W 为可用宽度与 N×120 的较大值，每列宽为 `120 + (W−N×120) × 权重 / 权重总和`。短列让出空间，长列获得更多空间；需求相同则仍均分。480 上限为最小列宽的 4 倍，进入共享 Layout token；列需求在表格 materialization/version 更新时计算或缓存，避免每帧重扫全文。两个 renderer 与估高使用相同规则，不按第一行或各行独立计算列宽。
5. C05 局部滚动与估高：120 最小宽、12/8 padding、表头/表体左右对齐、细分隔和稳定 table scroll id 保留。窄窗口只让表格横滚，不撑宽会话。表格估高逐行取各 cell 在分配后内容宽内的最大估计行数，再加每行上下 padding 和实际分隔线；列表内的表格先按 renderer 相同的条件（block 属于列表且当前 line 不是 `ListItem`）扣除 `(depth+1) × MARKDOWN_LIST_INDENT` 缩进。保留实际测量优先、宽度变化失效、源身份与阅读锚点。不扩大到其它 block 的估高重构。
6. C06 内容与范围：原文、可见复制规则、流式未闭合语法、历史恢复、代码块和其它 Markdown 语义不变。不修改 parser、运行状态、协议、持久化、配置、全局字号或主题颜色；不加依赖、非测试 unwrap/expect 或代码注释。
