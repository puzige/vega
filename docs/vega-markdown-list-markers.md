# Markdown 无序列表圆点

## 目标与范围

按用户提供的列表参考图，让会话 Markdown 无序列表的圆点更清晰：使用正文前景色和粗体圆点，不再使用次级灰色。保留系统字体的基线对齐，与首行正文对齐。

仅影响会话 Markdown 的无序列表标记，包括可选择正文和非选择渲染路径；有序编号继续使用次级色和原有字重。思考内容的独立文本布局不在本次范围。

不改变 Markdown 解析、标记字符 `•`、复制内容、列表缩进、行高、项间距、嵌套结构和任务复选框。

## 验证

本地只做格式和差异静态检查，不运行应用、构建或测试。云端 required CI 验证编译与检查。用户手测核对浅色/深色、普通列表、长文本换行、嵌套列表、有序列表、任务列表与选择复制；实际视觉与参考图的接近程度仍需手测确认。
