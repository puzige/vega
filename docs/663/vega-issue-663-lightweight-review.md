# #663 轻量化 Vega 独立审查门禁

## 授权、基线与范围

用户已明确授权接手并实现。裁决要点：**保留独立审查为合并前提**，但轻量化；**不设固定时限或轮数**。

实施基线：`f5891b29`。本规格先于实现固定。

仅改以下 5 个仓库协作文本文件，不改运行时、CI、分支保护或用户配置：

- `AGENTS.md`
- `docs/vega-exec-guide.md`
- `docs/vega-issue-workflow.md`
- `docs/vega-rust-test-delivery-lifecycle.md`
- `.agents/skills/vega-kanban-delivery/SKILL.md`

`.claude/skills/vega-kanban-delivery` 是指向 `.agents/skills/` 的软链，只改 canonical。

## 问题与证据

#640 / PR #645（合并为 `9a90ef74`）已把产品通用委派提示与项目交付规程分离。产品侧 `loop_.rs` 的审查段已收敛为条件式：「When review is authorized, focus on the current differences and affected contracts」。

仓库自身条文未同步，仍是旧形态：约 41 处重复强调非实现者、READY 交接、完整最终 head 门禁，**缺少审查范围与退出条件**。

已核实的耗时事实（仅作背景，不据此断言文本是唯一根因）：收尾审查子 Agent 常见 81–117 次模型请求、20–32 分钟；`review-630` 以 `reasoning_limit` 失败；工具执行 0.2–46s 可忽略，耗时来自模型推理。

已核实的分支保护事实：`required_approving_review_count: 0`，唯一强制项 `check (fmt, clippy, test)`，`strict: true`。**独立审查是纯文本约定**，本卡不触碰权限或 CI 配置。

## 实现契约与验收对照

| 验收 | 保留或收敛后的契约 | 落点/验证 |
|---|---|---|
| 1 独立审查仍为合并前提 | 由非该实现写入者承担，实现者自审不能替代 | AGENTS 按需委派与工作流、exec-guide §1/§2、issue-workflow、skill |
| 2 范围限定本次差异 | 审查本次差异及其受影响契约与不变量，不复述全量实现 | 新增范围条款；删除要求全量复述的旧表述 |
| 3 明确退出条件 | 证据充分即提交结论；无发现是正常结果，不为证明已审查而制造发现 | 新增退出条款 |
| 4 禁止重复审查 | 无新差异、新证据、新未决问题不重启审查；复用结论只审增量 | 统一既有「不重复无变化审查」，补足可判定条件 |
| 5 静态限制如实记录 | 静态无法确认项记为限制，不自动扩为新调查；可选建议不自动启动调查 | 新增边界条款 |
| 6 真实风险不被压过 | 结束条件不得略过未决真实风险与必要回归 | 保留并置于退出条款内 |
| 7 最终 head 为版本核对 | 确认完整最终 head 与 required check 结果，不重新审查全部实现 | 改写既有「完整最终 head」表述 |
| 8 不设固定数值 | 无时限、轮数、预算、自动通过/取消机制 | 全文禁用此类表述 |
| 9 五文件一致且不重复 | 同一规则在合适层级表达一次；历史 `docs/<编号>/` 不改写 | 差异与关键词核对 |

## 保留的完整性核心（不得弱化）

- 独立审查仍由非该实现写入者承担，实现者自审不能替代。
- 审查绑定已停写的精确内容版本；可与该版本既有 Actions 并行，二者不能相互替代。
- 真实未决风险与必要回归不得因结束条件被略过。
- required CI、权限边界、用户手测门禁不变。

## 非目标

- 不取消 Vega 仓库的非实现者独立审查、required CI、用户手测与安全边界。
- 不改 GitHub 分支保护、CI 拓扑、required check 名称或权限配置。
- 不改产品运行时提示、模型、reasoning、provider、调度器、schema。
- 不新增固定审查时限、最大轮数、模型预算或自动通过/自动取消机制。
- 不改写 `docs/<编号>/` 下既有历史记录。

## 验证与交付

- 本地仅低 CPU 静态检查：差异、格式、链接与关键词核对。不运行 Vega、编译、构建、测试或打包。
- 独立语义审查最终文本（非实现者，只读，绑定停写精确版本），逐项核对本表九项与保留契约。
- 既有云端 PR Check 验证最终 head；Rust 空集如实写 `no Rust tests`（0 发现/0 执行），不称行为测试通过。
- 实际审查耗时变化待规则生效后观察，记录任务规模、发现与返工；不承诺提速比例。
- 回滚经 PR 恢复文本，不动用户数据。
