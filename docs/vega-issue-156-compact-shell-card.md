# Issue #156：收起状态隐藏 Shell 命令正文

## 目标

收起的 Shell 工具卡只说明它在运行命令，并保留可辨认的运行状态；完整命令只在展开的详情中显示。这样长绝对路径和参数不会占满会话正文的单行空间。

## 用户可见行为

- 收起行不显示命令正文、路径、参数或换行后的命令内容。
- 收起行保留通用动作标签和真实状态：等待批准、运行中、已运行、拒绝、取消、失败。非零退出码仍表现为失败。
- 既有耗时、退出码、截断、复用等已验证元数据按现有规则保留；不推断或新增状态。
- 有 Shell 详情时保留右侧展开箭头；展开后显示未经缩写的 `$ <完整命令>`、输出和终态信息。折叠/展开仍由同一行交互控制。
- 该规则只改变 Shell 卡片的收起标题，不改变实际命令、审批、执行、输出存储或日志。
- 不增加公开 API、依赖或新的 UI token。

## 验收

- 定向单测覆盖等待批准、运行、成功、失败/非零退出、拒绝、取消的收起状态文案，不包含命令正文。
- 长绝对路径、带引号参数及多行命令在收起行不泄漏，展开详情仍逐字保留完整命令。
- 既有耗时、退出码、截断、复用、输出与损坏结果测试不回退。
- 在桌面应用中执行一个无副作用的只读命令：收起时只显示通用命令动作和状态；展开时可见原命令与结果。

## 范围外

不改变所有 Shell 默认折叠策略、工具卡默认展开策略、详情布局、输出截断策略或其它类型工具卡的标题。
