# MCP 不可用提示进入对话流

2026-10-25 用户截图修订：取代 `vega-mcp-input-notice.md` 中 composer 上方的固定提示与下次提交清理规则；参数换行契约不变。

## 验收

- MCP 不可用提示只在所属回合的对话流尾部显示一次，随内容滚动，不固定在 composer 上下，不使用 toast、卡片背景或边框。
- 使用现有红色错误文字、字号、换行与回合提示间距。保留数量、工具不可用的影响和设置恢复指引；不把非致命 MCP 问题标记为整轮失败。
- 所属回合由 controller 的 root message ID 显式传递，不从当前输入焦点或最新文本猜测。准备阶段尚无消息 ID 时暂存于 active run，出现所属消息后展示。
- 正常输出、折叠过程、回合结束、同会话下一轮与历史刷新期间，提示不转移到另一回合；真实 provider/压缩错误仍单独保留。重复批次按服务器去重。
- 在当前 stream 生命周期内按消息保留提示；不新增数据库 schema，不宣称重启应用后恢复未持久化诊断。历史刷新后在所属消息存在时可重新投影。滚动锚点估算包含提示高度。
- 无诊断不新增节点或空白。沿用已有英文/中文文案及主题 token，不新增解释文案或依赖。

## 验证

本地只做格式、差异与静态调用链检查，不运行 Vega、编译或测试。最终版本经非实现者独立审查与 Actions required checks；真实键盘、浅深色及滚动/折叠由用户手测。

## 范围

只修改 MCP 提示的所属回合、展示位置和布局估算，不修改 MCP 连接、凭据、工具执行或失败诊断策略。连接失败调查另行区分已证实配置事实与尚未取得的进程级证据。
