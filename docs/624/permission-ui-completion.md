# D4 权限界面与应用级重置收尾

本增量实现既有 D4 的 A7/A8/A13/A17/A21，不增加权限、平台、外部自动化或配置修改授权。原规格与未知效果的拒绝规则继续有效；本地仅静态检查，行为回归交既有 Actions，全部实现后统一独立 review。

## 线程和自动化授权

- 线程权限准备动作捕获数据库身份、ready epoch、线程的完整权限字段/revision，以及目标模式。等待用户时不持锁。FullAccess 与同名重新授权都出现独立确认，取消不修改线程；保存重新核对原身份、epoch、revision 与来源，提交后读回才发布。
- 已有运行的 fence 保持不变。权限控件修改的是之后的新运行，活动运行旁显示其实际模式；需要立即停止仍使用 Stop。线程未来权限编辑通过短协调门禁和 revision CAS，不借另一运行的 admission，也不替换运行内快照；其他任务模式/模型变更继续遵守各自门禁。
- 显式确认新草稿的 FullAccess 时，在同一事务内创建该精确草稿和 thread-scoped grant，不借后来的默认授权。保留原输入、模型和项目；失败/取消不产生已授权半成品。确认与保存均绑定原 stream、草稿及单调操作身份，迟到回执不能覆盖新路由/来源。
- 自动化的持久权限确认独立于线程确认。卡片明确目标、触发安排及该任务的范围，绑定 kind/identity/revision 和完整 fence；任务修改或线程重新授权后原确认失效。普通线程确认和默认授权不自动调用自动化授权服务。
- 默认权限服务已有独立确认与来源核对，继续保留。共享风险说明使用用户任务语言；确认默认聚焦取消，Tab/Shift-Tab/Enter/Space/Escape 均有明确行为。保存态防止重复提交，冲突和未知结果要求重新读取，不用旧确认重试。

## 应用级重置

- 通用设置提供“重置完全访问授权”入口。先只读准备原始配置/数据库/epoch 意图，确认明确会停止任务、暂停自动化、清除线程和未来默认的完全访问授权；既有文件和外部效果不会撤销。取消确认不暂停、不写配置或授权。
- 确认后由应用控制器持有精确数据库 pause，关闭自动派发，取消所有根运行、普通准备、排队等待和手动压缩，关闭其权限/问题卡。原执行者保留正常结束和释放路径；不改历史状态来制造排空。
- 收尾等待有界，超时、未知提交或不可确认的外部清理保持阻塞。界面提供真实失败、重试和定位未收尾事项的入口；未取得可信回执不能显示重置完成或可降级。既有成功的外部调用没有清理凭据时仍视为未知，不回填伪造回执。
- 静止后调用已有 journal/epoch/reset 服务，同一 pause 覆盖数据库撤权、配置保存、重放/重试失效与完成读回。pending 重试沿用同一 journal/epoch；提交结果未知不新建重置。失败保留 pause 与原证据；仅确认尚未进入持久重置且 epoch 未变时允许明确取消，已停止的任务和自动化不自动重启。
- 成功回执后仍持有 pause，先刷新线程、默认、自动化、队列和当前/缓存 stream 的权限投影，保留原输入与历史。全部刷新成功后才释放 pause 并显示完成；刷新失败只重试刷新，不再次轮换 epoch。普通成功反馈适时消退，失败和待处理事项持续可访问。

## 验证与停止条件

必要开发回归覆盖：取消和保存失败无写入；同名重授权；来源/epoch/数据库/任务身份变更拒绝；活动 run 的旧 fence 与未来设置分离；草稿事务原子性和迟到回执；自动化独立授权；重置确认前无副作用、pause 下拒绝新执行、已存在 owner 正常释放、未知效果不被完成状态覆盖、pending 重试幂等，以及 GPUI 窗口中的确认/错误/焦点和键盘路径。

不运行本机 Vega、原生进程、沙箱或真实凭据实验；profile 与服务回归不等同 OS 强度验证。云端失败先修责任层，不删除断言求通过。未知清理、来源冲突或最终 required CI 未通过时保持 Draft，不合并、不宣称整卡完成。
