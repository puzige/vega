# 更新胶囊左移 12px

## 目标与边界

用户确认：高度保持 28 个逻辑像素，更新胶囊整体向左移 12px，右侧三个图标的位置不变。延续 [#825 高度契约](../825/update-capsule-height.md)；本次仅增加胶囊与右侧控件组的分隔，不缩小字号、内边距或按钮。

## 验收用例

| 前置 / 操作 | 可观察结果 | 验证方式 |
|---|---|---|
| 同一窗口宽度，Available / Ready，中英文，浅深主题 | 胶囊左右边界均比改动前左移 12px，宽高不变；高度为 28px | 静态布局、云端编译；实际几何与观感待用户手测 |
| 默认 / hover / pressed / Tab 焦点 | 胶囊位置及尺寸稳定，原有状态反馈保留 | 静态差异；真实交互待用户手测 |

| 窄窗口、长标题、侧栏开关 | 标题按原规则截断，胶囊保持完整；右侧三个图标坐标及组内间距不变 | 静态布局；实际布局待用户手测 |
| 更新入口隐藏 | 不增加额外占位，右侧图标位置不变 | 静态条件核对；用户手测 |

## 最小实现

在 `render_main_header` 的 `vega-update-notice` 上增加 `mr_3()`（12px 右外边距）。现有标题 `flex_1` 吸收 12px 的空间变化，胶囊保持不收缩及内容自适应宽度。外边距随胶囊的条件渲染存在，不修改 header 的预留区，也不修改独立绝对定位的 `render_shell_slot_cluster`。

保留 28px 高度、文字居中、左右各 12px 内距、13px 字号、主题色、全圆角、显隐和全部事件处理。无更新逻辑、配置、数据、依赖或可见文案变化。

## 数值核对

- 原胶囊右边界为 R，宽度为 W；新增右外边距 12 后，右边界 R − 12，左边界 R − W − 12，宽度仍为 W。
- 高度仍为 `TITLEBAR_CONTROL_SIZE = 28px`，垂直位置不变。
- 右侧图标组独立 `right_0` 定位，代码不变；组坐标变化为 0。与胶囊的间隔在原有基础上增加 12px，不把原有间隔误称为 0。
