# Composer 右键编辑菜单

## 范围与根因

用户确认底部未发送的输入框没有右键菜单，未报告快捷键失效。基线 c42148f6 的 TextInput 已绑定 Copy/Cut/Paste/SelectAll，但没有右键入口。仅 composer 显式启用菜单，其他输入框及消息区不变。

## 行为契约

- 右键显示剪切、复制、粘贴、全选，使用现有菜单组件及中英文标签。
- 右键不移动光标或清除选区；复制只复制选区，剪切只删除选区。
- 无选区时剪切/复制禁用；空文本时全选禁用。masked 输入禁止剪切/复制。
- 菜单动作通过输入框 focus handle 发送现有动作，保留粘贴的图片、文本与 IME 处理，不另读或记录剪贴板。
- 菜单支持键盘导航、Escape/外部点击关闭；执行动作回到输入框。现有快捷键、发送、换行不变。
- 不新增常驻说明、通知或依赖。

## 验证

本地仅格式、diff 和静态检查，不运行 Vega、编译或测试。不为此入口补充临时 Rust 测试。独立审查检查选区、焦点、动作路由及作用域；完整 required CI 交 Actions。

用户手测：中英文多行选区右键复制/剪切，空选区禁用，全选后复制，文本及图片粘贴，Escape/外部关闭后继续输入，⌘C/⌘V 回归；浅深色和窗口边缘菜单可见。手测未完成不能声称行为验收通过。
