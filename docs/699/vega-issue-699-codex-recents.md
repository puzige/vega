# Recents 对齐 Codex

## 授权与范围

用户要求按提供的 Codex 对照图实现。本规格只改变项目对话是否出现在 Recents，不实现 #588 的按项目/扁平视图分派，也不接管该卡写入者。用户本次要求取代旧规格中「Recents 永远只含独立对话」这一默认规则；其余既有组织能力保持。

## 行为契约

1. Pinned 保持独占：任何置顶对话均不进入 Recents，项目组继续排除置顶对话。
2. Recents 默认显示所有非置顶对话，包含项目对话；Projects 中原项目入口不受影响。Recents 内每个对话只出现一次。
3. Recents 标题行增加菜单入口，复用现有侧边栏菜单、焦点、Escape、上下方向键、Tab、Enter/Space 行为。菜单项「显示项目对话 / Show project conversations」呈现当前选中状态。开关关闭后只显示独立且非置顶对话，重新开启恢复项目对话。
4. 通过既有 revision-checked SetPreferences 持久化 `hide_project_threads_from_recents`，缺字段按 false 处理，因此旧配置和新配置默认均显示项目对话。无需数据库迁移；不改项目绑定、分组、消息或排序记录。写入失败沿用现有错误提示，不提前伪造已保存状态。
5. 活跃及按需显示的归档对话使用同一筛选规则；现有 sorted_threads、渐进分页、行菜单和导航保持。开关不重置其他偏好。
6. 本次不改手动排序语义：仍按现有项目/置顶区域排序，不允许跨项目拖动；不增加项目名副标题或常驻说明。

## 验收矩阵

| 场景 | 预期 |
| --- | --- |
| 新配置 / 旧偏好缺新字段 | 独立、项目非置顶对话都在 Recents；项目组保留原入口 |
| 开关关闭 / 重新开启 | 仅独立非置顶 / 所有非置顶；选中态反映已保存快照 |
| 重启 | 开关状态保留 |
| 独立或项目对话置顶 / 取消置顶 | 从 Recents 移除 / 按当前开关恢复；Pinned 不重复 |
| 归档隐藏 / 显示 | 归档仅在显示时参与，且同样排除置顶和被开关隐藏的项目对话 |
| 超过分页窗口 | 计数、渐进加载基于筛选结果，不重复、不漏后续窗口 |
| 菜单键盘与取消 | 可通过焦点进入，方向键/Tab 选择，Enter/Space 切换；Escape 关闭而不离开会话 |
| 打开、重命名、删除 | 沿用原行为；项目入口与 Recents 中的同一对话同步更新 |

## 验证与交付边界

本地只做低 CPU 差异、格式、静态检查，不运行 Vega、不编译或执行测试。自动验证由 Actions 完整 required PR check 承担，合并前须由非实现写入者独立审查最终差异。真实运行、重启、键盘及原生视觉由用户手测；CI 和合并不代表安装或用户验收。不为本任务增加将进入 master 的 Rust 测试，不修改 CI 或现有 Python 测试。
