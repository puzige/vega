# Issue #72：长会话消息锚点导航

状态：规格冻结，等待实现。

来源：<https://github.com/puzige/vega/issues/72> 及 2026-09-22 的范围澄清评论。原始截图展示对话滚动区旁的纵向锚点轨道；范围是位置指示、悬停预览与点击跳转，不是 #148 的虚拟滚动和长会话性能工作。

## 目标

让用户在长会话中快速识别自己所在的位置，预览会话中的消息，并跳到选中的消息。定位使用稳定消息 ID，能衔接当前历史分页和虚拟列表，不依赖易变的列表索引。

## 交互契约

- 在可滚动会话内容左侧显示窄锚点轨道。轨道覆盖会话列表的可滚动高度，不侵入消息卡片、嵌套工具卡或固定 Composer 的可点击区域。
- 会话只有在内容溢出可视区域且至少有两个可定位条目时显示轨道；短会话不显示空轨道。
- 每个可定位的持久化消息对应一个稳定锚点，使用消息 ID 作为路由键。锚点包含可访问名称和轻量类别提示；重复的流式片段不会产生重复锚点。无持久化消息 ID 的瞬时状态不生成锚点。
- 锚点沿轨道按条目在会话中的顺序分布。当前位置标记反映滚动视口在会话中的位置；滚动、条目高度变化、窗口宽度变化及加载相邻历史页后，位置与锚点顺序保持一致。
- 悬停或键盘聚焦锚点时，在轨道旁显示短文本预览。预览取该消息的纯文本投影，限制长度并省略多余空白；不显示凭据、原始工具输入、完整工具输出或 Markdown 原文。预览不会捕获滚轮或键盘输入。
- 点击锚点定位到对应消息，并遵循 #148 的稳定 ID 定位路径：已加载目标直接滚入视口；未加载目标先读取包含它的历史页，再定位。不得扫描或合并非相邻历史页。目标不属于当前会话时保持当前位置并显示可恢复的 not-found 状态。
- 在任务执行期间，可立即跳转到已加载消息；未加载目标应延迟到本次运行结束后再换入目标历史页。切换会话后过期的跳转请求不得影响新会话。
- 用户主动跳转后进入普通离底滚动状态；若原本处于跟随底部，跳转必须停止跟随，直到用户再次滚到底部。历史页加载失败不应丢失当前可见位置，且不得触发无限重试。
- 支持鼠标与键盘使用；轨道及预览采用现有主题 token，并在不同窗口宽度、浅色/深色主题和辅助功能字号下保持可见。

## 验收

- 短会话没有轨道；长会话显示与持久化消息一一对应的稳定锚点，不随流式更新、展开/折叠或相邻分页插入而错配。
- 当前位置标记随滚动更新，条目重测或列宽变化后仍对应同一消息身份。
- 鼠标悬停和键盘聚焦均可显示被截断的安全文本预览；焦点可见、读屏名称明确，预览不遮挡正文或 Composer。
- 点击当前加载页和未加载历史页中的锚点均精确定位；during-run deferred target、A→B→A 路由切换、foreign/missing ID 与 history load failure 均有回归覆盖。
- 跳转目标采用真实 `message_id` 验证，不仅断言滚动索引；定位动作不会请求 provider、改变对话、改变消息内容或丢失当前选中的会话。
- Computer Use 在集成桌面端验证轨道显示、当前位置、hover 预览、键盘访问、鼠标跳转、历史分页以及 Composer 与消息内容未被遮挡。

## 非目标

- 不重新实现 #148 的虚拟化、性能基准、历史分页、滚动锚点恢复或长会话内存管理。
- 不为跳转持久化列表索引，不复制/缓存旧的 `ConversationStream` 实体，不更换 GPUI 列表。
- 不添加搜索、书签、章节编辑、对话导出或消息操作菜单。
- 不改会话的持久化 schema、provider 请求或现有消息渲染语义。

## 实现约束

- 复用 #148 的稳定 entry identity、消息 ID 定位事件、历史分页和 route-generation 防护；如果当前接口无法覆盖某条契约，先报告原因并扩展既有路径，避免另建第二套定位服务。
- 位置计算必须使用列表的实际条目几何或有界测量结果，不能假设消息卡片等高，也不能为了绘制整条轨道而挂载所有虚拟行。
- 定向 GPUI/store 回归和当前 UI 视觉验证由实现代理完成；主 Agent 审查范围、合并 PR，并在最新集成构建上执行 Computer Use 验收。
