# 侧栏左侧留白与对齐

## 用户确认与范围

侧栏宽度保持不变，顶层分组标题、任务标题和项目文件夹图标统一距窗口左缘 24 逻辑像素。选中与 hover 背景距左右边缘各 12px，内部左侧留 12px。本规格覆盖旧侧栏左侧负 margin / 表面外扩几何；不改变侧栏宽度、持久化、行高、右侧操作槽或交互。

## 几何与实现

- 外层 `SIDEBAR_PADDING = 12` 保持不变；主滚动区移除负 margin 与额外 padding，表面范围为 `[12, W - 12]`，宽 `W - 24`。
- `SIDEBAR_LABEL_INSET = 12` 同时用于分组标题、顶层任务和项目行内部左侧留白，起点 `12 + 12 = 24`。
- Pinned / Recents 和项目行移除 8px 表面外扩；不变更右边界或右侧操作槽。
- 项目内任务保留 24px 层级差：`SIDEBAR_ROW_INSET = 36`，起点 `12 + 36 = 48`，与项目图标相差 `48 - 24 = 24`。项目内 Show more 同轴；顶层 Show more 与顶层标题同轴。
- 重命名输入框已有 8px padding + 1px border，顶层 wrapper inset 为 `12 - 9 = 3`，输入文字起点 `12 + 3 + 9 = 24`。保留共享输入框 chrome 与焦点行为。
- New task 和 Settings 图标使用同样 12px 内部左留白；不改其右侧快捷键位置。顶部导航和 Settings 页面不受影响。
- 不新增可见文案、设置、依赖或存储变更。

低风险布局变更，不为流程新建 Rust 测试。本地仅差异、格式与静态链路检查；完整编译、Clippy、Python 回归和 Rust 清点由最终 head 的 required CI 完成。合并须非实现者独立审查，UI 由用户手测。
