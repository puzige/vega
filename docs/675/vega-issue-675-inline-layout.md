# #675 · 行内排版快照与消息气泡

## 契约

用户消息 `为什么这个卡最后被拖回来了https://github.com/puzige/vega/issues/632` 在窄宽度换行后，全部行盒必须落在气泡内。保持现有字号、颜色、圆角、70% 最大宽度及内距，不裁切、不固定高度、不改写 URL。

InlineFlow 的测量可能被布局引擎多次调用，且引擎会缓存尺寸。不能将最后一次测量的可变结果当作最终结果。保留按测量宽度区分的完整 FlowLayout 快照，预绘制按最终边界选择对应快照；同一快照的片段范围、坐标、宽度用于文字元素、选择以及链接区域。快照宽高按设备像素匹配布局尺寸；优先复用与最终边界匹配的测量快照；没有匹配快照时按最终宽度及 white-space 重算作为防御兜底，该兜底不能修正容器高度，气泡高度正确性由块级自然布局保证。片段继续 nowrap，图标宽度计入测量且只在链接开始出现。内容宽度保留分数逻辑像素，由 GPUI 统一按设备像素取整；不先向上取整到整个逻辑像素，以免 Retina 分数宽度下合法快照被拒绝。

气泡正文使用块级纵向自然布局，而不是 flex 列：避免 flex 在 max-width 收窄后仍将早期单行主轴高度作为已知高度传给文字叶节点。块级子节点在最终内容宽度下自然测量全部行高；普通与可选择消息路径一致修改，外层右对齐不变。
