# Issue #82：供应商设置减少说明文字

状态：规格冻结，等待实现。

来源：<https://github.com/puzige/vega/issues/82> 的原始截图。截图展示 Settings → Providers 的供应商详情页；主要冗余段落是 `测试会发送少量固定文本请求；不会使用聊天内容。`。凭据行中的遮蔽值与“已存储”是凭据状态反馈，不属于该说明段落。

## 目标

清理供应商详情页常驻说明文字，并将用户在执行连接/模型测试前需要了解的内容放到一个紧邻相关操作的帮助图标中。

## 交互契约

- 移除 `测试会发送少量固定文本请求；不会使用聊天内容。` 这一常驻段落，不保留原高度的空白占位。
- 在“发现模型”及各模型“测试”操作附近放置一个紧凑的帮助图标；用户悬停或键盘聚焦时显示单一提示：`测试会发送少量固定文本请求；不会使用聊天内容。`
- 图标有明确的无障碍名称、可见键盘焦点样式；提示可通过现有 tooltip/help affordance 访问，不需要点击或发送网络请求。
- 保留“•••••• 已存储”与“需重新输入 API Key”等真实凭据状态；不展示、复制或记录凭据正文。
- 不改变提供商启用状态、发现模型、模型测试、Pi Agent 导入、设置持久化和运行结果提示。该卡不决定 #81 的 Pi Agent 范围。
- 其他字段、按钮顺序和详情页布局保持稳定；窄窗口下帮助图标不挤出、遮挡或禁用相邻控件。

## 验收

- 原说明不再占据详情页常驻布局，帮助图标紧邻模型发现/测试操作。
- 鼠标悬停和键盘聚焦会显示同一段说明；移出/失焦后提示正常隐藏。
- 点击模型测试仍沿用既有固定文本请求；不读入当前会话内容，不改变 provider 请求体与成功/失败反馈。
- 已存储凭据和缺失凭据两种状态仍正确显示；API key 继续遮蔽。
- 深浅主题、窄窗布局、鼠标和键盘交互有定向 UI 回归；Computer Use 在集成桌面端检查说明不常驻、图标位置和测试按钮仍可操作。

## 非目标

- 不改变测试请求内容、模型发现、网络调用或凭据处理。
- 不移除或重写 Pi Agent 凭据导入功能；#81 需要单独明确产品范围。
- 不改其他设置页面的说明文案。

## 当前行为补充

本规格冻结时，#82 只保证其改动没有触碰当时存在的 Pi Agent 导入控件；该点是历史范围隔离记录。Pi 导入现已按 [Issue #81](vega-issue-81-remove-pi-agent.md) 移除。当前及后续 Provider 设置验收应断言该入口不存在，同时继续检查凭据状态、手动编辑与启用/禁用行为。
